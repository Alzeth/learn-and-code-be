# Урок 2

## Ціль

Навчитись писати прості програми. Перевірити налаштування середовища програмування.

## Засоби

- Основна робота проходитиме в терміналі
- Нам потрібен лише командний рядок, в який ми надсилаємо текстові команди
- Для набору тексту програми достатньо базового текстового редактора
- Спершу запустимо класичну програму `Hello, World!`
- Використаємо вбудовану функцію `print()`

## Перша програма

Створимо новий файл `filename.py` та додамо до нього наш код.
Найпростіша програма вміщається в один рядок:

```python
print("Hello, World!")
```

Запустити програму можна набравши в терміналі:

```bash
python filename.py
```

Результат:

```
Hello, World!
```

## Характеристики цієї програми

Дана програма:

- не приймає вхідних даних
- виводить дані в термінал
- не містить циклів та повторень

## Додаткові приклади

`print()` може приймати декілька параметрів — пробіл між ними з'явиться автоматично:

```python
# Це коментар — він не впливає на код
print('Hello,', 'World!')
```

Інший спосіб — конкатенація (склеювання) рядків:

```python
# Зверніть увагу на пробіл в кінці першого слова
print('Hello, ' + 'World!')
```

> **Примітка:** функції — це частини коду, які ми пишемо самі,
> або вже готові блоки з вхідними та вихідними даними.
