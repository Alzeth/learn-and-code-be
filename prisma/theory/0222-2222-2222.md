## Ціль

Вивчити змінні та типи даних. Написати програму, яка виводить ім'я та вік.

## Що таке змінна?

Змінна — це іменована комірка пам'яті, в якій ми зберігаємо значення. Уяви коробку з підписом: підпис — це ім'я змінної, а те, що всередині — її значення.

```python
name = "Олексій"
age = 12
```

## Основні типи даних

| Тип | Назва | Приклад |
|-----|-------|---------|
| `str` | Рядок (текст) | `"Привіт"` |
| `int` | Ціле число | `42` |
| `float` | Дробове число | `3.14` |
| `bool` | Логічне значення | `True`, `False` |

Дізнатись тип змінної можна за допомогою функції `type()`:

```python
name = "Олексій"
age = 12
print(type(name))   # <class 'str'>
print(type(age))    # <class 'int'>
```

## Перша програма

Створимо файл `lesson2.py` з програмою, яка виводить ім'я та вік:

```python
name = "Олексій"
age = 12

print("Мене звати", name)
print("Мені", age, "років")
```

Результат:

```
Мене звати Олексій
Мені 12 років
```

## Підстановка змінних у рядок (f-string)

Зручніший спосіб вставляти змінні в текст — використати **f-рядки**. Перед лапками ставимо букву `f`, а змінні пишемо у фігурних дужках `{}`:

```python
name = "Олексій"
age = 12

print(f"Мене звати {name}, мені {age} років.")
```

Результат:

```
Мене звати Олексій, мені 12 років.
```

## Введення даних від користувача

Функція `input()` дозволяє отримати текст від користувача з клавіатури:

```python
name = input("Як тебе звати? ")
age = input("Скільки тобі років? ")

print(f"Привіт, {name}! Тобі {age} років.")
```

> **Увага:** `input()` завжди повертає рядок (`str`). Щоб отримати число, потрібно перетворити: `age = int(input("Вік: "))`.
