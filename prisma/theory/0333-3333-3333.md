## Арифметичні операції

Python вміє виконувати всі основні математичні дії:

| Операція | Символ | Приклад | Результат |
|----------|--------|---------|-----------|
| Додавання | `+` | `5 + 3` | `8` |
| Віднімання | `-` | `10 - 4` | `6` |
| Множення | `*` | `3 * 7` | `21` |
| Ділення | `/` | `9 / 2` | `4.5` |
| Ціле ділення | `//` | `9 // 2` | `4` |
| Остача від ділення | `%` | `9 % 2` | `1` |
| Степінь | `**` | `2 ** 8` | `256` |

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

## Перетворення типів

Щоб виконати математику з числами, введеними користувачем, потрібно перетворити рядок на число:

```python
text = "42"
number = int(text)    # рядок → ціле число
price = float("3.99") # рядок → дробове число
```

## Калькулятор

Створимо файл `calculator.py`:

```python
a = int(input("Введи перше число: "))
b = int(input("Введи друге число: "))

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
```

Приклад роботи:

```
Введи перше число: 8
Введи друге число: 3
8 + 3 = 11
8 - 3 = 5
```

## Порядок виконання операцій

Python дотримується звичних математичних правил: спочатку `**`, потім `*`, `/`, `//`, `%`, і лише потім `+`, `-`. Для зміни порядку використовуй дужки:

```python
print(2 + 3 * 4)    # 14  (спочатку множення)
print((2 + 3) * 4)  # 20  (спочатку дужки)
```

> **Порада:** якщо сумніваєшся — постав дужки. Вони роблять код зрозумілішим.
