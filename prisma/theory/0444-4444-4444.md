## Ціль

Вивчити умовні оператори (if, else). Написати програму, яка визначає, чи є число парним.

## Що таке умовний оператор?

Умовний оператор дозволяє програмі **приймати рішення**: виконувати різний код залежно від того, чи виконується певна умова.

```python
if умова:
    # цей блок виконується, якщо умова True
else:
    # цей блок виконується, якщо умова False
```

> **Важливо:** відступи (4 пробіли або Tab) — це частина синтаксису Python. Без них код не працює.

## Оператори порівняння

| Оператор | Значення | Приклад |
|----------|----------|---------|
| `==` | рівно | `5 == 5` → `True` |
| `!=` | не рівно | `5 != 3` → `True` |
| `>` | більше | `7 > 3` → `True` |
| `<` | менше | `2 < 9` → `True` |
| `>=` | більше або рівно | `5 >= 5` → `True` |
| `<=` | менше або рівно | `4 <= 6` → `True` |

## Парне чи непарне?

Число парне, якщо остача від ділення на 2 дорівнює нулю (`number % 2 == 0`).

Створимо файл `even_odd.py`:

```python
number = int(input("Введи число: "))

if number % 2 == 0:
    print(f"{number} — парне число")
else:
    print(f"{number} — непарне число")
```

Приклад роботи:

```
Введи число: 7
7 — непарне число
```

## Кілька умов: elif

Якщо варіантів більше двох, використовуй `elif` (скорочення від "else if"):

```python
score = int(input("Введи оцінку: "))

if score >= 90:
    print("Відмінно!")
elif score >= 70:
    print("Добре")
elif score >= 50:
    print("Задовільно")
else:
    print("Треба більше практики")
```

## Логічні оператори

Умови можна об'єднувати:

| Оператор | Значення | Приклад |
|----------|----------|---------|
| `and` | і | `x > 0 and x < 10` |
| `or` | або | `x < 0 or x > 100` |
| `not` | не | `not x == 5` |

```python
age = int(input("Скільки тобі років? "))

if age >= 6 and age <= 12:
    print("Ти школяр молодших класів")
```

> **Порада:** читай умову вголос — якщо вона звучить природно, значить написана правильно.
