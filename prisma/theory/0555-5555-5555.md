## Ціль

Познайомитись з циклами (for, while). Створити програму, яка рахує від 1 до 10.

## Навіщо потрібні цикли?

Цикл дозволяє **повторювати** блок коду кілька разів, не копіюючи його вручну. Без циклу вивести числа від 1 до 10 виглядало б так:

```python
print(1)
print(2)
# ... і ще 8 рядків
```

З циклом — набагато коротше.

## Цикл for

Цикл `for` зручно використовувати, коли наперед відомо, скільки разів повторювати.

Функція `range(n)` генерує числа від `0` до `n-1`:

```python
for i in range(10):
    print(i)   # виведе 0, 1, 2, ..., 9
```

Щоб рахувати від `1` до `10`:

```python
for i in range(1, 11):
    print(i)
```

Результат:

```
1
2
3
...
10
```

`range()` також приймає крок — третій аргумент:

```python
for i in range(0, 20, 2):
    print(i)   # 0, 2, 4, 6, ..., 18 (лише парні)
```

## Цикл while

Цикл `while` повторюється, **поки виконується умова**:

```python
count = 1

while count <= 10:
    print(count)
    count += 1   # те саме, що count = count + 1
```

Результат — такий самий: числа від 1 до 10.

## break і continue

- `break` — **зупиняє** цикл достроково
- `continue` — **пропускає** поточну ітерацію і переходить до наступної

```python
for i in range(1, 11):
    if i == 5:
        continue   # пропустити 5
    if i == 8:
        break      # зупинитись на 8
    print(i)

# Виведе: 1 2 3 4 6 7
```

## Коли що використовувати?

| Ситуація | Цикл |
|----------|------|
| Відома кількість повторень | `for` |
| Повторювати, поки виконується умова | `while` |
| Перебирати елементи списку | `for` |

> **Обережно:** якщо умова `while` ніколи не стане хибною — цикл буде нескінченним. Завжди перевіряй, що змінна в умові змінюється всередині циклу.
