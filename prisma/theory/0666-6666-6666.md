## Що таке список?

Список (`list`) — це впорядкована колекція значень в одній змінній. Уяви список як пронумеровану шафу з полицями.

```python
friends = ["Олексій", "Марія", "Іван", "Софія"]
```

## Звернення до елементів

Елементи нумеруються з **0** (не з 1):

```python
friends = ["Олексій", "Марія", "Іван", "Софія"]

print(friends[0])   # Олексій
print(friends[1])   # Марія
print(friends[-1])  # Софія (останній елемент)
```

## Основні операції

```python
friends = ["Олексій", "Марія"]

# Додати елемент в кінець
friends.append("Іван")

# Дізнатись кількість елементів
print(len(friends))   # 3

# Перевірити наявність елемента
print("Марія" in friends)   # True

# Видалити елемент за значенням
friends.remove("Марія")

# Видалити елемент за індексом
del friends[0]
```

## Перебір списку циклом

Найзручніший спосіб вивести всі елементи — цикл `for`:

```python
friends = ["Олексій", "Марія", "Іван", "Софія"]

for friend in friends:
    print(f"Привіт, {friend}!")
```

Результат:

```
Привіт, Олексій!
Привіт, Марія!
Привіт, Іван!
Привіт, Софія!
```

## Програма зі списком друзів

Створимо файл `friends.py`:

```python
friends = []

print("Додай імена друзів (порожній рядок — завершити):")

while True:
    name = input("Ім'я: ")
    if name == "":
        break
    friends.append(name)

print(f"\nТвої друзі ({len(friends)}):")
for i, friend in enumerate(friends, start=1):
    print(f"{i}. {friend}")
```

Приклад роботи:

```
Ім'я: Олексій
Ім'я: Марія
Ім'я: 
Твої друзі (2):
1. Олексій
2. Марія
```

## Корисні методи списку

| Метод | Що робить |
|-------|-----------|
| `list.append(x)` | Додає `x` в кінець |
| `list.insert(i, x)` | Вставляє `x` на позицію `i` |
| `list.remove(x)` | Видаляє перший `x` |
| `list.sort()` | Сортує за алфавітом / за зростанням |
| `list.reverse()` | Перевертає список |
| `list.index(x)` | Повертає індекс `x` |

> **Порада:** `enumerate()` одночасно дає і порядковий номер, і значення — дуже зручно для нумерованих списків.
