## Що таке функція?

Функція — це **іменований блок коду**, який можна викликати будь-яку кількість разів. Функції допомагають не повторювати один і той самий код.

Ти вже знайомий з вбудованими функціями: `print()`, `input()`, `len()`, `int()`. Тепер навчимося писати власні.

## Оголошення функції

```python
def greet(name):
    print(f"Привіт, {name}!")
```

- `def` — ключове слово для оголошення функції
- `greet` — ім'я функції
- `name` — параметр (вхідні дані)
- тіло функції — з відступом

## Виклик функції

```python
greet("Олексій")   # Привіт, Олексій!
greet("Марія")     # Привіт, Марія!
greet("Іван")      # Привіт, Іван!
```

Один раз написали — можна використовувати скільки завгодно разів.

## Функція з кількома параметрами

```python
def greet(name, time_of_day):
    print(f"Добрий {time_of_day}, {name}!")

greet("Олексій", "ранок")   # Добрий ранок, Олексій!
greet("Марія", "вечір")     # Добрий вечір, Марія!
```

## Значення за замовчуванням

Параметру можна задати значення, яке використовується якщо аргумент не передано:

```python
def greet(name, time_of_day="день"):
    print(f"Добрий {time_of_day}, {name}!")

greet("Іван")            # Добрий день, Іван!
greet("Іван", "ранок")   # Добрий ранок, Іван!
```

## Повернення значення

Функція може **повертати** результат за допомогою `return`:

```python
def add(a, b):
    return a + b

result = add(5, 3)
print(result)   # 8
```

Після `return` функція завершується — наступний код у ній не виконується.

## Повна програма

Створимо файл `greeting.py`:

```python
def greet(name):
    print(f"Привіт, {name}! Раді бачити тебе.")

def farewell(name):
    print(f"До побачення, {name}! Побачимось наступного разу.")

name = input("Як тебе звати? ")
greet(name)
farewell(name)
```

Приклад роботи:

```
Як тебе звати? Олексій
Привіт, Олексій! Раді бачити тебе.
До побачення, Олексій! Побачимось наступного разу.
```
