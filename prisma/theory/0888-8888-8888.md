## Що таке словник?

Словник (`dict`) — це колекція пар **ключ: значення**. На відміну від списку (де елементи пронумеровані), у словнику кожне значення має свою унікальну назву-ключ.

Уяви реальний словник: слово (ключ) → пояснення (значення).

```python
toy = {
    "name": "Лего",
    "color": "різнокольорове",
    "pieces": 500
}
```

## Доступ до значень

```python
toy = {"name": "Лего", "color": "різнокольорове", "pieces": 500}

print(toy["name"])    # Лего
print(toy["pieces"])  # 500
```

Безпечніший спосіб — метод `.get()` (повертає `None` замість помилки, якщо ключа немає):

```python
print(toy.get("price"))        # None
print(toy.get("price", "—"))   # —  (значення за замовчуванням)
```

## Додавання та зміна

```python
toy = {"name": "Лего"}

toy["color"] = "червоне"    # додати новий ключ
toy["name"] = "Лего Сіті"   # змінити існуюче значення

print(toy)   # {'name': 'Лего Сіті', 'color': 'червоне'}
```

## Видалення

```python
del toy["color"]      # видалити за ключем
toy.pop("pieces")     # видалити та отримати значення
```

## Перебір словника

```python
toy = {"name": "Лего", "color": "червоне", "pieces": 500}

# лише ключі
for key in toy:
    print(key)

# лише значення
for value in toy.values():
    print(value)

# ключ і значення разом
for key, value in toy.items():
    print(f"{key}: {value}")
```

## Програма з іграшками

Створимо файл `toys.py`:

```python
toys = {}

print("Додай інформацію про улюблену іграшку:")
name = input("Назва: ")
color = input("Колір: ")
pieces = input("Кількість деталей (або Enter): ")

toys[name] = {
    "color": color,
    "pieces": int(pieces) if pieces else None
}

print("\nТвоя іграшка:")
for key, value in toys[name].items():
    if value is not None:
        print(f"  {key}: {value}")
```

Приклад роботи:

```
Назва: Лего
Колір: червоне
Кількість деталей: 250

Твоя іграшка:
  color: червоне
  pieces: 250
```

## Список словників

Словники часто зберігають у списках, щоб описати колекцію об'єктів:

```python
toys = [
    {"name": "Лего", "pieces": 500},
    {"name": "Пазл", "pieces": 1000},
    {"name": "Кубик Рубіка", "pieces": 26},
]

for toy in toys:
    print(f"{toy['name']} — {toy['pieces']} деталей")
```

> **Порада:** використовуй словники, коли дані мають назви (ім'я, вік, колір). Використовуй списки, коли важливий лише порядок.
