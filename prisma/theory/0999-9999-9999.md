# Урок 9

## Ціль

Ознайомитись з обробкою помилок. Написати програму, яка просить ввести число і обробляє помилки введення.

## Що таке помилки?

Коли програма натрапляє на щось несподіване — вона зупиняється і виводить **помилку (виняток)**. Наприклад, якщо спробувати перетворити текст на число:

```python
number = int("привіт")   # ValueError: invalid literal for int()
```

Щоб програма не падала, потрібно **перехопити** помилку.

## Конструкція try / except

```python
try:
    # код, який може викликати помилку
    number = int(input("Введи число: "))
    print(f"Ти ввів: {number}")
except ValueError:
    print("Це не число! Спробуй ще раз.")
```

- Блок `try` — виконується спочатку
- Блок `except` — виконується лише якщо в `try` виникла помилка вказаного типу

## Типи помилок

| Тип | Коли виникає |
|-----|--------------|
| `ValueError` | Неправильний формат значення (`int("abc")`) |
| `ZeroDivisionError` | Ділення на нуль (`10 / 0`) |
| `IndexError` | Звернення за межі списку (`list[100]`) |
| `KeyError` | Відсутній ключ словника (`dict["xxx"]`) |
| `TypeError` | Несумісні типи (`"5" + 5`) |

Можна перехоплювати кілька типів одночасно:

```python
try:
    result = int(input("Число: ")) / int(input("Дільник: "))
    print(result)
except ValueError:
    print("Введи ціле число")
except ZeroDivisionError:
    print("На нуль ділити не можна!")
```

## Блок else і finally

- `else` — виконується якщо помилок **не було**
- `finally` — виконується **завжди**, незалежно від помилок

```python
try:
    number = int(input("Введи число: "))
except ValueError:
    print("Помилка: це не число")
else:
    print(f"Чудово! Ти ввів {number}")
finally:
    print("Програма завершена")
```

## Програма з перевіркою введення

Створимо файл `safe_input.py` — програма не завершиться, поки користувач не введе коректне число:

```python
while True:
    try:
        number = int(input("Введи ціле число: "))
        break   # виходимо з циклу, якщо введення коректне
    except ValueError:
        print("Помилка! Введи саме число, без літер та пробілів.")

print(f"Дякую! Ти ввів число {number}.")
```

Приклад роботи:

```
Введи ціле число: привіт
Помилка! Введи саме число, без літер та пробілів.
Введи ціле число: 3.14
Помилка! Введи саме число, без літер та пробілів.
Введи ціле число: 42
Дякую! Ти ввів число 42.
```

> **Правило:** перехоплюй лише ті помилки, які ти очікуєш і вмієш обробляти. Не пиши `except Exception` без потреби — це може приховати справжні баги в програмі.
