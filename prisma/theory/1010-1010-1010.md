## Модуль random

Щоб комп'ютер загадав випадкове число, використаємо вбудований модуль `random`:

```python
import random

secret = random.randint(1, 100)   # випадкове ціле від 1 до 100
print(secret)
```

`import` підключає готовий модуль. `random.randint(a, b)` повертає випадкове число **включно** з `a` і `b`.

## Покрокова побудова гри

### Крок 1 — загадати число

```python
import random

secret = random.randint(1, 100)
```

### Крок 2 — попросити ввести здогадку

```python
guess = int(input("Вгадай число від 1 до 100: "))
```

### Крок 3 — порівняти та підказати

```python
if guess < secret:
    print("Більше!")
elif guess > secret:
    print("Менше!")
else:
    print("Правильно!")
```

### Крок 4 — повторювати до правильної відповіді

```python
while guess != secret:
    guess = int(input("Спробуй ще: "))
    if guess < secret:
        print("Більше!")
    elif guess > secret:
        print("Менше!")

print("Правильно!")
```

## Повна гра

Створимо файл `guess.py`:

```python
import random

def get_guess():
    while True:
        try:
            return int(input("Твоя здогадка: "))
        except ValueError:
            print("Введи ціле число!")

def play():
    secret = random.randint(1, 100)
    attempts = 0

    print("Я загадав число від 1 до 100. Спробуй вгадати!")

    while True:
        guess = get_guess()
        attempts += 1

        if guess < secret:
            print("Більше! Спробуй ще.")
        elif guess > secret:
            print("Менше! Спробуй ще.")
        else:
            print(f"Правильно! Ти вгадав за {attempts} спроб.")
            break

play()
```

Приклад роботи:

```
Я загадав число від 1 до 100. Спробуй вгадати!
Твоя здогадка: 50
Більше! Спробуй ще.
Твоя здогадка: 75
Менше! Спробуй ще.
Твоя здогадка: 63
Правильно! Ти вгадав за 3 спроб.
```
