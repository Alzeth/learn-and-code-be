# Lektion 1

## Ziel

Einfache Programme schreiben lernen. Die Programmierumgebung einrichten und testen.

## Werkzeuge

- Die Hauptarbeit findet im Terminal statt
- Wir benötigen nur die Kommandozeile, in die wir Textbefehle eingeben
- Zum Schreiben des Programmcodes reicht ein einfacher Texteditor
- Zuerst starten wir das klassische Programm `Hello, World!`
- Wir verwenden die eingebaute Funktion `print()`

## Das erste Programm

Erstelle eine neue Datei `filename.py` und füge unseren Code hinzu.
Das einfachste Programm besteht aus einer einzigen Zeile:

```python
print("Hello, World!")
```

Das Programm kann im Terminal mit folgendem Befehl gestartet werden:

```bash
python filename.py
```

Ergebnis:

```
Hello, World!
```

## Eigenschaften dieses Programms

Dieses Programm:

- nimmt keine Eingabedaten entgegen
- gibt Daten im Terminal aus
- enthält keine Schleifen oder Wiederholungen

## Weitere Beispiele

`print()` kann mehrere Parameter entgegennehmen — ein Leerzeichen zwischen ihnen wird automatisch eingefügt:

```python
# Das ist ein Kommentar — er hat keinen Einfluss auf den Code
print('Hello,', 'World!')
```

Eine andere Möglichkeit — Verkettung (Zusammenfügen) von Zeichenketten:

```python
# Beachte das Leerzeichen am Ende des ersten Wortes
print('Hello, ' + 'World!')
```

> **Hinweis:** Funktionen sind Codeabschnitte, die wir selbst schreiben,
> oder bereits fertige Bausteine mit Ein- und Ausgabedaten.
