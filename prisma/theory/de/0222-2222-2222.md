Variablen und Datentypen kennenlernen. Ein Programm schreiben, das Name und Alter ausgibt.

## Was ist eine Variable?

Eine Variable ist ein benannter Speicherplatz, in dem wir einen Wert ablegen. Stell dir eine beschriftete Schachtel vor: die Beschriftung ist der Variablenname, und was darin liegt — ihr Wert.

```python
name = "Max"
age = 12
```

## Grundlegende Datentypen

| Typ | Name | Beispiel |
|-----|------|---------|
| `str` | Zeichenkette (Text) | `"Hallo"` |
| `int` | Ganze Zahl | `42` |
| `float` | Dezimalzahl | `3.14` |
| `bool` | Wahrheitswert | `True`, `False` |

Den Typ einer Variable kann man mit der Funktion `type()` ermitteln:

```python
name = "Max"
age = 12
print(type(name))   # <class 'str'>
print(type(age))    # <class 'int'>
```

## Das erste Programm

Erstelle die Datei `lesson2.py` mit einem Programm, das Name und Alter ausgibt:

```python
name = "Max"
age = 12

print("Mein Name ist", name)
print("Ich bin", age, "Jahre alt")
```

Ergebnis:

```
Mein Name ist Max
Ich bin 12 Jahre alt
```

## Variablen in Zeichenketten einsetzen (f-string)

Eine praktischere Methode, Variablen in Text einzufügen — **f-Strings**. Vor den Anführungszeichen steht der Buchstabe `f`, und Variablen werden in geschweifte Klammern `{}` geschrieben:

```python
name = "Max"
age = 12

print(f"Mein Name ist {name}, ich bin {age} Jahre alt.")
```

Ergebnis:

```
Mein Name ist Max, ich bin 12 Jahre alt.
```

## Eingabe vom Benutzer

Die Funktion `input()` erlaubt es, Text vom Benutzer über die Tastatur zu empfangen:

```python
name = input("Wie heißt du? ")
age = input("Wie alt bist du? ")

print(f"Hallo, {name}! Du bist {age} Jahre alt.")
```

> **Achtung:** `input()` gibt immer eine Zeichenkette (`str`) zurück. Um eine Zahl zu erhalten, muss sie umgewandelt werden: `age = int(input("Alter: "))`.
