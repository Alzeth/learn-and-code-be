## Arithmetische Operationen

Python kann alle grundlegenden mathematischen Operationen ausführen:

| Operation | Symbol | Beispiel | Ergebnis |
|-----------|--------|---------|----------|
| Addition | `+` | `5 + 3` | `8` |
| Subtraktion | `-` | `10 - 4` | `6` |
| Multiplikation | `*` | `3 * 7` | `21` |
| Division | `/` | `9 / 2` | `4.5` |
| Ganzzahldivision | `//` | `9 // 2` | `4` |
| Rest der Division | `%` | `9 % 2` | `1` |
| Potenz | `**` | `2 ** 8` | `256` |

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

## Typumwandlung

Um mit vom Benutzer eingegebenen Zahlen rechnen zu können, muss die Zeichenkette in eine Zahl umgewandelt werden:

```python
text = "42"
number = int(text)    # Zeichenkette → ganze Zahl
price = float("3.99") # Zeichenkette → Dezimalzahl
```

## Rechner

Erstelle die Datei `calculator.py`:

```python
a = int(input("Gib die erste Zahl ein: "))
b = int(input("Gib die zweite Zahl ein: "))

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
```

Beispielausgabe:

```
Gib die erste Zahl ein: 8
Gib die zweite Zahl ein: 3
8 + 3 = 11
8 - 3 = 5
```

## Reihenfolge der Operationen

Python hält sich an die üblichen mathematischen Regeln: zuerst `**`, dann `*`, `/`, `//`, `%`, und danach erst `+`, `-`. Um die Reihenfolge zu ändern, verwende Klammern:

```python
print(2 + 3 * 4)    # 14  (zuerst Multiplikation)
print((2 + 3) * 4)  # 20  (zuerst Klammern)
```

> **Tipp:** Wenn du unsicher bist — setze Klammern. Sie machen den Code verständlicher.
