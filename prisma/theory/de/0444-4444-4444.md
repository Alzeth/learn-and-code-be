## Ziel

Bedingte Anweisungen (if, else) kennenlernen. Ein Programm schreiben, das prüft, ob eine Zahl gerade ist.

## Was ist eine bedingte Anweisung?

Eine bedingte Anweisung erlaubt es dem Programm, **Entscheidungen zu treffen**: unterschiedlichen Code auszuführen, je nachdem ob eine bestimmte Bedingung erfüllt ist.

```python
if Bedingung:
    # dieser Block wird ausgeführt, wenn die Bedingung True ist
else:
    # dieser Block wird ausgeführt, wenn die Bedingung False ist
```

> **Wichtig:** Einrückungen (4 Leerzeichen oder Tab) sind Teil der Python-Syntax. Ohne sie funktioniert der Code nicht.

## Vergleichsoperatoren

| Operator | Bedeutung | Beispiel |
|----------|-----------|---------|
| `==` | gleich | `5 == 5` → `True` |
| `!=` | ungleich | `5 != 3` → `True` |
| `>` | größer als | `7 > 3` → `True` |
| `<` | kleiner als | `2 < 9` → `True` |
| `>=` | größer oder gleich | `5 >= 5` → `True` |
| `<=` | kleiner oder gleich | `4 <= 6` → `True` |

## Gerade oder ungerade?

Eine Zahl ist gerade, wenn der Rest der Division durch 2 gleich null ist (`number % 2 == 0`).

Erstelle die Datei `even_odd.py`:

```python
number = int(input("Gib eine Zahl ein: "))

if number % 2 == 0:
    print(f"{number} ist eine gerade Zahl")
else:
    print(f"{number} ist eine ungerade Zahl")
```

Beispielausgabe:

```
Gib eine Zahl ein: 7
7 ist eine ungerade Zahl
```

## Mehrere Bedingungen: elif

Wenn es mehr als zwei Möglichkeiten gibt, verwende `elif` (Kurzform für "else if"):

```python
score = int(input("Gib die Note ein: "))

if score >= 90:
    print("Ausgezeichnet!")
elif score >= 70:
    print("Gut")
elif score >= 50:
    print("Befriedigend")
else:
    print("Mehr Übung ist nötig")
```

## Logische Operatoren

Bedingungen können verknüpft werden:

| Operator | Bedeutung | Beispiel |
|----------|-----------|---------|
| `and` | und | `x > 0 and x < 10` |
| `or` | oder | `x < 0 or x > 100` |
| `not` | nicht | `not x == 5` |

```python
age = int(input("Wie alt bist du? "))

if age >= 6 and age <= 12:
    print("Du bist ein Grundschüler")
```

> **Tipp:** Lies die Bedingung laut vor — wenn sie sich natürlich anhört, ist sie richtig geschrieben.
