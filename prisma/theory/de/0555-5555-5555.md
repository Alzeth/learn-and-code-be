# Lektion 5

## Ziel

Schleifen (for, while) kennenlernen. Ein Programm erstellen, das von 1 bis 10 zählt.

## Wozu braucht man Schleifen?

Eine Schleife erlaubt es, einen Codeblock **mehrfach zu wiederholen**, ohne ihn manuell zu kopieren. Ohne Schleife würde die Ausgabe der Zahlen von 1 bis 10 so aussehen:

```python
print(1)
print(2)
# ... und noch 8 weitere Zeilen
```

Mit einer Schleife geht es viel kürzer.

## Die for-Schleife

Die `for`-Schleife eignet sich, wenn die Anzahl der Wiederholungen im Voraus bekannt ist.

Die Funktion `range(n)` erzeugt Zahlen von `0` bis `n-1`:

```python
for i in range(10):
    print(i)   # gibt 0, 1, 2, ..., 9 aus
```

Um von `1` bis `10` zu zählen:

```python
for i in range(1, 11):
    print(i)
```

Ergebnis:

```
1
2
3
...
10
```

`range()` akzeptiert auch eine Schrittweite als drittes Argument:

```python
for i in range(0, 20, 2):
    print(i)   # 0, 2, 4, 6, ..., 18 (nur gerade Zahlen)
```

## Die while-Schleife

Die `while`-Schleife wiederholt sich, **solange die Bedingung erfüllt ist**:

```python
count = 1

while count <= 10:
    print(count)
    count += 1   # dasselbe wie count = count + 1
```

Das Ergebnis ist dasselbe: Zahlen von 1 bis 10.

## break und continue

- `break` — **beendet** die Schleife vorzeitig
- `continue` — **überspringt** die aktuelle Iteration und geht zur nächsten

```python
for i in range(1, 11):
    if i == 5:
        continue   # 5 überspringen
    if i == 8:
        break      # bei 8 stoppen
    print(i)

# Gibt aus: 1 2 3 4 6 7
```

## Wann welche Schleife verwenden?

| Situation | Schleife |
|-----------|----------|
| Anzahl der Wiederholungen bekannt | `for` |
| Wiederholen, solange Bedingung gilt | `while` |
| Elemente einer Liste durchgehen | `for` |

> **Vorsicht:** Wenn die Bedingung der `while`-Schleife niemals falsch wird — läuft die Schleife endlos. Stelle immer sicher, dass die Variable in der Bedingung innerhalb der Schleife verändert wird.
