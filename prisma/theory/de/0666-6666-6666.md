## Ziel

Listen kennenlernen. Ein Programm schreiben, das Freundesnamen speichert und ausgibt.

## Was ist eine Liste?

Eine Liste (`list`) ist eine geordnete Sammlung von Werten in einer einzigen Variable. Stell dir eine Liste wie einen nummerierten Schrank mit Fächern vor.

```python
friends = ["Max", "Anna", "Tim", "Laura"]
```

## Zugriff auf Elemente

Elemente werden ab **0** nummeriert (nicht ab 1):

```python
friends = ["Max", "Anna", "Tim", "Laura"]

print(friends[0])   # Max
print(friends[1])   # Anna
print(friends[-1])  # Laura (letztes Element)
```

## Grundlegende Operationen

```python
friends = ["Max", "Anna"]

# Element am Ende hinzufügen
friends.append("Tim")

# Anzahl der Elemente ermitteln
print(len(friends))   # 3

# Vorhandensein eines Elements prüfen
print("Anna" in friends)   # True

# Element nach Wert entfernen
friends.remove("Anna")

# Element nach Index entfernen
del friends[0]
```

## Liste mit einer Schleife durchgehen

Der praktischste Weg, alle Elemente auszugeben — die `for`-Schleife:

```python
friends = ["Max", "Anna", "Tim", "Laura"]

for friend in friends:
    print(f"Hallo, {friend}!")
```

Ergebnis:

```
Hallo, Max!
Hallo, Anna!
Hallo, Tim!
Hallo, Laura!
```

## Programm mit Freundesliste

Erstelle die Datei `friends.py`:

```python
friends = []

print("Füge Freundesnamen hinzu (leere Eingabe zum Beenden):")

while True:
    name = input("Name: ")
    if name == "":
        break
    friends.append(name)

print(f"\nDeine Freunde ({len(friends)}):")
for i, friend in enumerate(friends, start=1):
    print(f"{i}. {friend}")
```

Beispielausgabe:

```
Name: Max
Name: Anna
Name: 
Deine Freunde (2):
1. Max
2. Anna
```

## Nützliche Listenmethoden

| Methode | Was sie tut |
|---------|-------------|
| `list.append(x)` | Fügt `x` am Ende hinzu |
| `list.insert(i, x)` | Fügt `x` an Position `i` ein |
| `list.remove(x)` | Entfernt das erste `x` |
| `list.sort()` | Sortiert alphabetisch / aufsteigend |
| `list.reverse()` | Kehrt die Liste um |
| `list.index(x)` | Gibt den Index von `x` zurück |

> **Tipp:** `enumerate()` liefert gleichzeitig die laufende Nummer und den Wert — sehr praktisch für nummerierte Listen.
