# Lektion 7

## Ziel

Funktionen kennenlernen. Eine Funktion erstellen, die den Benutzer mit Namen begrüßt.

## Was ist eine Funktion?

Eine Funktion ist ein **benannter Codeblock**, der beliebig oft aufgerufen werden kann. Funktionen helfen dabei, denselben Code nicht zu wiederholen.

Du kennst bereits eingebaute Funktionen: `print()`, `input()`, `len()`, `int()`. Jetzt lernen wir, eigene zu schreiben.

## Funktion deklarieren

```python
def greet(name):
    print(f"Hallo, {name}!")
```

- `def` — Schlüsselwort zur Deklaration einer Funktion
- `greet` — Name der Funktion
- `name` — Parameter (Eingabedaten)
- Funktionsrumpf — eingerückt

## Funktion aufrufen

```python
greet("Max")    # Hallo, Max!
greet("Anna")   # Hallo, Anna!
greet("Tim")    # Hallo, Tim!
```

Einmal geschrieben — beliebig oft verwendbar.

## Funktion mit mehreren Parametern

```python
def greet(name, time_of_day):
    print(f"Guten {time_of_day}, {name}!")

greet("Max", "Morgen")    # Guten Morgen, Max!
greet("Anna", "Abend")    # Guten Abend, Anna!
```

## Standardwerte

Einem Parameter kann ein Standardwert zugewiesen werden, der verwendet wird, wenn kein Argument übergeben wird:

```python
def greet(name, time_of_day="Tag"):
    print(f"Guten {time_of_day}, {name}!")

greet("Tim")             # Guten Tag, Tim!
greet("Tim", "Morgen")   # Guten Morgen, Tim!
```

## Rückgabewert

Eine Funktion kann ein Ergebnis mit `return` **zurückgeben**:

```python
def add(a, b):
    return a + b

result = add(5, 3)
print(result)   # 8
```

Nach `return` wird die Funktion beendet — nachfolgender Code in ihr wird nicht mehr ausgeführt.

## Vollständiges Programm

Erstelle die Datei `greeting.py`:

```python
def greet(name):
    print(f"Hallo, {name}! Schön, dich zu sehen.")

def farewell(name):
    print(f"Auf Wiedersehen, {name}! Bis zum nächsten Mal.")

name = input("Wie heißt du? ")
greet(name)
farewell(name)
```

Beispielausgabe:

```
Wie heißt du? Max
Hallo, Max! Schön, dich zu sehen.
Auf Wiedersehen, Max! Bis zum nächsten Mal.
```

> **Tipp:** Gib Funktionen Verbalnamen, die ihre Aktion beschreiben: `greet`, `calculate`, `print_result`. So liest sich der Code wie normaler Text.
