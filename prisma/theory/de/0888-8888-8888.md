## Ziel

Wörterbücher kennenlernen. Ein Programm schreiben, das Informationen über Lieblingsspielzeug speichert.

## Was ist ein Wörterbuch?

Ein Wörterbuch (`dict`) ist eine Sammlung von **Schlüssel-Wert-Paaren**. Anders als bei einer Liste (wo Elemente nummeriert sind), hat in einem Wörterbuch jeder Wert seinen eigenen eindeutigen Schlüssel.

Stell dir ein echtes Wörterbuch vor: Wort (Schlüssel) → Erklärung (Wert).

```python
toy = {
    "name": "Lego",
    "color": "bunt",
    "pieces": 500
}
```

## Zugriff auf Werte

```python
toy = {"name": "Lego", "color": "bunt", "pieces": 500}

print(toy["name"])    # Lego
print(toy["pieces"])  # 500
```

Sicherer Zugriff — Methode `.get()` (gibt `None` zurück statt eines Fehlers, wenn der Schlüssel fehlt):

```python
print(toy.get("price"))        # None
print(toy.get("price", "—"))   # —  (Standardwert)
```

## Hinzufügen und Ändern

```python
toy = {"name": "Lego"}

toy["color"] = "rot"         # neuen Schlüssel hinzufügen
toy["name"] = "Lego City"    # vorhandenen Wert ändern

print(toy)   # {'name': 'Lego City', 'color': 'rot'}
```

## Entfernen

```python
del toy["color"]      # nach Schlüssel löschen
toy.pop("pieces")     # löschen und Wert zurückgeben
```

## Wörterbuch durchlaufen

```python
toy = {"name": "Lego", "color": "rot", "pieces": 500}

# nur Schlüssel
for key in toy:
    print(key)

# nur Werte
for value in toy.values():
    print(value)

# Schlüssel und Wert zusammen
for key, value in toy.items():
    print(f"{key}: {value}")
```

## Programm mit Spielzeug

Erstelle die Datei `toys.py`:

```python
toys = {}

print("Füge Informationen über dein Lieblingsspielzeug hinzu:")
name = input("Name: ")
color = input("Farbe: ")
pieces = input("Anzahl der Teile (oder Enter): ")

toys[name] = {
    "color": color,
    "pieces": int(pieces) if pieces else None
}

print("\nDein Spielzeug:")
for key, value in toys[name].items():
    if value is not None:
        print(f"  {key}: {value}")
```

## Liste von Wörterbüchern

Wörterbücher werden häufig in Listen gespeichert, um eine Sammlung von Objekten zu beschreiben:

```python
toys = [
    {"name": "Lego", "pieces": 500},
    {"name": "Puzzle", "pieces": 1000},
    {"name": "Zauberwürfel", "pieces": 26},
]

for toy in toys:
    print(f"{toy['name']} — {toy['pieces']} Teile")
```

> **Tipp:** Verwende Wörterbücher, wenn die Daten Namen haben (Name, Alter, Farbe). Verwende Listen, wenn nur die Reihenfolge wichtig ist.
