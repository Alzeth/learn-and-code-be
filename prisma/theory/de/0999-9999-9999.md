# Lektion 9

## Ziel

Fehlerbehandlung kennenlernen. Ein Programm schreiben, das den Benutzer zur Zahleneingabe auffordert und Eingabefehler behandelt.

## Was sind Fehler?

Wenn ein Programm auf etwas Unerwartetes trifft — hält es an und gibt einen **Fehler (Exception)** aus. Zum Beispiel beim Versuch, Text in eine Zahl umzuwandeln:

```python
number = int("hallo")   # ValueError: invalid literal for int()
```

Damit das Programm nicht abstürzt, muss der Fehler **abgefangen** werden.

## Die try / except-Konstruktion

```python
try:
    # Code, der einen Fehler verursachen könnte
    number = int(input("Gib eine Zahl ein: "))
    print(f"Du hast eingegeben: {number}")
except ValueError:
    print("Das ist keine Zahl! Versuche es erneut.")
```

- Der `try`-Block — wird zuerst ausgeführt
- Der `except`-Block — wird nur ausgeführt, wenn im `try`-Block ein Fehler des angegebenen Typs aufgetreten ist

## Fehlertypen

| Typ | Wann er auftritt |
|-----|-----------------|
| `ValueError` | Falsches Werteformat (`int("abc")`) |
| `ZeroDivisionError` | Division durch null (`10 / 0`) |
| `IndexError` | Zugriff außerhalb der Listengrenzen (`list[100]`) |
| `KeyError` | Fehlender Wörterbuchschlüssel (`dict["xxx"]`) |
| `TypeError` | Inkompatible Typen (`"5" + 5`) |

Mehrere Fehlertypen können gleichzeitig abgefangen werden:

```python
try:
    result = int(input("Zahl: ")) / int(input("Divisor: "))
    print(result)
except ValueError:
    print("Gib eine ganze Zahl ein")
except ZeroDivisionError:
    print("Division durch null ist nicht erlaubt!")
```

## Die else- und finally-Blöcke

- `else` — wird ausgeführt, wenn **kein** Fehler aufgetreten ist
- `finally` — wird **immer** ausgeführt, unabhängig von Fehlern

```python
try:
    number = int(input("Gib eine Zahl ein: "))
except ValueError:
    print("Fehler: das ist keine Zahl")
else:
    print(f"Super! Du hast {number} eingegeben")
finally:
    print("Programm beendet")
```

## Programm mit Eingabeprüfung

Erstelle die Datei `safe_input.py` — das Programm wird nicht beendet, bis der Benutzer eine gültige Zahl eingibt:

```python
while True:
    try:
        number = int(input("Gib eine ganze Zahl ein: "))
        break
    except ValueError:
        print("Fehler! Gib nur eine Zahl ein, ohne Buchstaben und Leerzeichen.")

print(f"Danke! Du hast die Zahl {number} eingegeben.")
```

> **Regel:** Fange nur die Fehler ab, die du erwartest und behandeln kannst. Schreibe `except Exception` nicht ohne triftigen Grund — das kann echte Fehler im Programm verbergen.
