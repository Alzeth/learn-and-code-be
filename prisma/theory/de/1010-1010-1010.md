## Das Modul random

Damit der Computer eine zufällige Zahl ausdenkt, verwenden wir das eingebaute Modul `random`:

```python
import random

secret = random.randint(1, 100)
print(secret)
```

`import` lädt ein fertiges Modul. `random.randint(a, b)` gibt eine zufällige Zahl zurück — **einschließlich** `a` und `b`.

## Schrittweiser Aufbau des Spiels

### Schritt 1 — Zahl ausdenken

### Schritt 2 — Tipp eingeben lassen

guess = int(input("Errate eine Zahl von 1 bis 100: "))

### Schritt 3 — Vergleichen und Hinweis geben

```python

    print("Größer!")
elif guess > secret:
    print("Kleiner!")

    print("Richtig!")
```

### Schritt 4 — Wiederholen bis zur richtigen Antwort

```python
while guess != secret:
    guess = int(input("Versuche es nochmal: "))
    if guess < secret:
        print("Größer!")
    elif guess > secret:
        print("Kleiner!")

print("Richtig!")
```

## Das vollständige Spiel

Erstelle die Datei `guess.py`:

```python
import random

def get_guess():
    while True:
        try:
            return int(input("Dein Tipp: "))
        except ValueError:
            print("Gib eine ganze Zahl ein!")

def play():
    secret = random.randint(1, 100)
    attempts = 0

    print("Ich habe mir eine Zahl von 1 bis 100 gedacht. Versuch sie zu erraten!")

    while True:
        guess = get_guess()
        attempts += 1

        if guess < secret:
            print("Größer! Versuche es nochmal.")
        elif guess > secret:
            print("Kleiner! Versuche es nochmal.")
        else:
            print(f"Richtig! Du hast es in {attempts} Versuchen erraten.")
            break

play()
```

## Ideen zur Erweiterung

Das Spiel ist fertig — aber es kann noch interessanter gemacht werden:

- Die Anzahl der Versuche begrenzen (z. B. 7) und „Du hast verloren!" ausgeben, wenn sie aufgebraucht sind
- Den Rekord (wenigste Versuche) speichern und nach jedem Spiel anzeigen
- Dem Spieler die Wahl des Schwierigkeitsgrades ermöglichen: leicht (1–10), mittel (1–100), schwer (1–1000)
- Fragen, ob der Spieler noch einmal spielen möchte
