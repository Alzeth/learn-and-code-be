# Lección 1
## Objetivo
Aprender a escribir programas simples. Verificar la configuración del entorno de programación.
## Herramientas
- El trabajo principal se realizará en la terminal
- Solo necesitamos la línea de comandos, donde enviamos comandos de texto
- Para escribir el código del programa basta con un editor de texto básico
- Primero ejecutaremos el clásico programa `Hello, World!`
- Usaremos la función integrada `print()`
## Primer programa
Creemos un nuevo archivo `filename.py` y agreguémosle nuestro código. El programa más simple cabe en una sola línea:
```python
print("Hello, World!")
```
Para ejecutar el programa, escribe en la terminal:
```bash
python filename.py
```
Resultado:
```
Hello, World!
```
## Características de este programa
Este programa:
- no recibe datos de entrada
- muestra datos en la terminal
- no contiene bucles ni repeticiones
## Ejemplos adicionales
`print()` puede recibir varios parámetros — el espacio entre ellos aparecerá automáticamente:
```python
# Esto es un comentario — no afecta al código
print('Hello,', 'World!')
```
Otra forma — concatenación (unión) de cadenas:
```python
# Fíjate en el espacio al final de la primera palabra
print('Hello, ' + 'World!')
```
> **Nota:** las funciones son partes del código que escribimos nosotros mismos, o bloques ya listos con datos de entrada y salida.
