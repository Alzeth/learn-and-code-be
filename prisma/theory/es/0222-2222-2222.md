# Lección 2
## Objetivo
Aprender variables y tipos de datos. Escribir un programa que muestre el nombre y la edad.
## ¿Qué es una variable?
Una variable es una celda de memoria con nombre donde almacenamos un valor. Imagina una caja con una etiqueta: la etiqueta es el nombre de la variable y lo que hay dentro es su valor.
```python
name = "Alejandro"
age = 12
```
## Tipos de datos básicos
| Tipo | Nombre | Ejemplo |
|------|--------|---------|
| `str` | Cadena (texto) | `"Hola"` |
| `int` | Número entero | `42` |
| `float` | Número decimal | `3.14` |
| `bool` | Valor lógico | `True`, `False` |
Para saber el tipo de una variable se usa la función `type()`:
```python
name = "Alejandro"
age = 12
print(type(name))   # <class 'str'>
print(type(age))    # <class 'int'>
```
## Primer programa
Creemos el archivo `lesson2.py` con un programa que muestre el nombre y la edad:
```python
name = "Alejandro"
age = 12

print("Tengo", age, "años")
```
Resultado:
```

Tengo 12 años
```
## Sustitución de variables en una cadena (f-string)
Una forma más cómoda de insertar variables en texto es usar **f-strings**. Se pone la letra `f` antes de las comillas y las variables se escriben entre llaves `{}`:
```python
name = "Alejandro"
age = 12
print(f"Me llamo {name}, tengo {age} años.")
```
Resultado:
```
Me llamo Alejandro, tengo 12 años.
```
## Entrada de datos del usuario
La función `input()` permite obtener texto del usuario desde el teclado:
```python
name = input("¿Cómo te llamas? ")
age = input("¿Cuántos años tienes? ")
print(f"¡Hola, {name}! Tienes {age} años.")
```
> **Atención:** `input()` siempre devuelve una cadena (`str`). Para obtener un número hay que convertirlo: `age = int(input("Edad: "))`.
