## Objetivo
Familiarizarse con las operaciones numéricas. Crear una calculadora de suma y resta.
## Operaciones aritméticas
Python puede realizar todas las operaciones matemáticas básicas:
| Operación | Símbolo | Ejemplo | Resultado |
|-----------|---------|---------|-----------|
| Suma | `+` | `5 + 3` | `8` |
| Resta | `-` | `10 - 4` | `6` |
| Multiplicación | `*` | `3 * 7` | `21` |
| División | `/` | `9 / 2` | `4.5` |
| División entera | `//` | `9 // 2` | `4` |
| Resto de la división | `%` | `9 % 2` | `1` |
| Potencia | `**` | `2 ** 8` | `256` |
```python
a = 10
b = 3
print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```
## Conversión de tipos
Para hacer operaciones matemáticas con números ingresados por el usuario, hay que convertir la cadena a número:
```python
text = "42"
number = int(text)    # cadena → número entero
price = float("3.99") # cadena → número decimal
```
## Calculadora
Creemos el archivo `calculator.py`:
```python
a = int(input("Introduce el primer número: "))
b = int(input("Introduce el segundo número: "))
print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
```
Ejemplo de ejecución:
```
Introduce el primer número: 8
Introduce el segundo número: 3
8 + 3 = 11
8 - 3 = 5
```
## Orden de las operaciones
Python sigue las reglas matemáticas habituales: primero `**`, luego `*`, `/`, `//`, `%`, y finalmente `+`, `-`. Para cambiar el orden usa paréntesis:
```python
print(2 + 3 * 4)    # 14  (primero la multiplicación)
print((2 + 3) * 4)  # 20  (primero los paréntesis)
```
> **Consejo:** si tienes dudas — pon paréntesis. Hacen el código más comprensible.
