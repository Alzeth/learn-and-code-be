# Lección 4
## Objetivo
Aprender los operadores condicionales (if, else). Escribir un programa que determine si un número es par.
## ¿Qué es un operador condicional?
El operador condicional permite que el programa **tome decisiones**: ejecutar código diferente dependiendo de si se cumple cierta condición.
```python
if condición:
    # este bloque se ejecuta si la condición es True
else:
    # este bloque se ejecuta si la condición es False
```
> **Importante:** la indentación (4 espacios o Tab) es parte de la sintaxis de Python. Sin ella el código no funciona.
## Operadores de comparación
| Operador | Significado | Ejemplo |
|----------|-------------|---------|
| `==` | igual a | `5 == 5` → `True` |
| `!=` | distinto de | `5 != 3` → `True` |
| `>` | mayor que | `7 > 3` → `True` |
| `<` | menor que | `2 < 9` → `True` |
| `>=` | mayor o igual que | `5 >= 5` → `True` |
| `<=` | menor o igual que | `4 <= 6` → `True` |
## ¿Par o impar?
Un número es par si el resto de la división por 2 es cero (`number % 2 == 0`).
Creemos el archivo `even_odd.py`:
```python
number = int(input("Introduce un número: "))
if number % 2 == 0:
    print(f"{number} es un número par")
else:
    print(f"{number} es un número impar")
```
Ejemplo de ejecución:
```
Introduce un número: 7
7 es un número impar
```
## Varias condiciones: elif
Si hay más de dos opciones, usa `elif` (abreviatura de "else if"):
```python
score = int(input("Introduce la puntuación: "))
if score >= 90:
    print("¡Excelente!")
elif score >= 70:
    print("Bien")
elif score >= 50:
    print("Suficiente")
else:
    print("Necesitas más práctica")
```
## Operadores lógicos
| Operador | Significado | Ejemplo |
|----------|-------------|---------|
| `and` | y | `x > 0 and x < 10` |
| `or` | o | `x < 0 or x > 100` |
| `not` | no | `not x == 5` |
```python
age = int(input("¿Cuántos años tienes? "))
if age >= 6 and age <= 12:
    print("Eres un alumno de primaria")
```
> **Consejo:** lee la condición en voz alta — si suena natural, está bien escrita.
