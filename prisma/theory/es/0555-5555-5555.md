# Lección 5
## Objetivo
Familiarizarse con los bucles (for, while). Crear un programa que cuente del 1 al 10.
## ¿Para qué sirven los bucles?
Un bucle permite **repetir** un bloque de código varias veces. Sin bucle, mostrar los números del 1 al 10 se vería así:
```python
print(1)
print(2)
# ... y 8 líneas más
```
## Bucle for
```python
for i in range(10):
    print(i)   # mostrará 0, 1, 2, ..., 9
```
Para contar del `1` al `10`:
```python
for i in range(1, 11):
    print(i)
```
`range()` también acepta un paso:
```python
for i in range(0, 20, 2):
    print(i)   # 0, 2, 4, 6, ..., 18 (solo pares)
```
## Bucle while
```python
count = 1
while count <= 10:
    print(count)
    count += 1   # lo mismo que count = count + 1
```
## break y continue
- `break` — **detiene** el bucle antes de tiempo
- `continue` — **salta** la iteración actual
```python
for i in range(1, 11):
    if i == 5:
        continue   # saltar el 5
    if i == 8:
        break      # detenerse en el 8
    print(i)
# Mostrará: 1 2 3 4 6 7
```
## ¿Cuándo usar cada uno?
| Situación | Bucle |
|-----------|-------|
| Número de repeticiones conocido | `for` |
| Repetir mientras se cumpla una condición | `while` |
| Recorrer elementos de una lista | `for` |
> **Cuidado:** si la condición del `while` nunca se vuelve falsa — el bucle será infinito.
