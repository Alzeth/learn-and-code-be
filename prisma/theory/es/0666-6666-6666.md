# Lección 6
## Objetivo
Aprender las listas. Escribir un programa que guarde nombres de amigos y los muestre.
## ¿Qué es una lista?
Una lista (`list`) es una colección ordenada de valores en una sola variable.
```python
friends = ["Alejandro", "María", "Carlos", "Sofía"]
```
## Acceso a los elementos (numeración desde 0):
```python
print(friends[0])   # Alejandro
print(friends[-1])  # Sofía (el último)
```
## Operaciones básicas:
```python
friends.append("Carlos")
print(len(friends))
friends.remove("María")
del friends[0]
```
## Recorrido:
```python
for friend in friends:
    print(f"¡Hola, {friend}!")
```
## Programa friends.py:
```python
friends = []
while True:
    name = input("Nombre: ")
    if name == "":
        break
    friends.append(name)
print(f"\nTus amigos ({len(friends)}):")
for i, friend in enumerate(friends, start=1):
    print(f"{i}. {friend}")
```
## Métodos útiles:
| Método | Qué hace |
|--------|----------|
| `append(x)` | Agrega al final |
| `insert(i, x)` | Inserta en la posición |
| `remove(x)` | Elimina el primer x |
| `sort()` | Ordena |
| `reverse()` | Invierte |
| `index(x)` | Devuelve el índice |
> **Consejo:** `enumerate()` proporciona el número de orden y el valor al mismo tiempo.
