## Objetivo
Familiarizarse con las funciones. Crear una función que salude al usuario por su nombre.
## ¿Qué es una función?
Una función es un **bloque de código con nombre** que se puede llamar cualquier número de veces.
```python
def greet(name):
    print(f"¡Hola, {name}!")
```
```python
greet("Alejandro")
greet("María")
```
## Varios parámetros:
```python
def greet(name, time_of_day):
    print(f"¡Buenos {time_of_day}, {name}!")
greet("Alejandro", "días")
```
## Valores por defecto:
```python
def greet(name, time_of_day="días"):
    print(f"¡Buenos {time_of_day}, {name}!")
greet("Carlos")
```
## Return:
```python
def add(a, b):
    return a + b
result = add(5, 3)
print(result)   # 8
```
## Programa completo greeting.py:
```python
def greet(name):
    print(f"¡Hola, {name}! Nos alegra verte.")
def farewell(name):
    print(f"¡Hasta luego, {name}! Nos vemos la próxima vez.")
name = input("¿Cómo te llamas? ")
greet(name)
farewell(name)
```
