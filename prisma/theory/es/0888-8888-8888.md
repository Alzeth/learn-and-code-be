# Lección 8
## Objetivo
Aprender los diccionarios. Escribir un programa que guarde información sobre juguetes favoritos.
## ¿Qué es un diccionario?
```python
toy = {"name": "Lego", "color": "multicolor", "pieces": 500}
```
## Acceso: toy["name"], toy.get("price", "—")
## Agregar/cambiar/eliminar: toy["color"] = "rojo", del toy["color"], toy.pop("pieces")
## Recorrido: for key in toy / for value in toy.values() / for key, value in toy.items()
## Programa toys.py:
```python
toys = {}
name = input("Nombre: ")
color = input("Color: ")
pieces = input("Número de piezas: ")
toys[name] = {"color": color, "pieces": int(pieces) if pieces else None}
for key, value in toys[name].items():
    if value is not None:
        print(f"  {key}: {value}")
```
## Lista de diccionarios:
```python
toys = [{"name": "Lego", "pieces": 500}, {"name": "Puzzle", "pieces": 1000}]
for toy in toys:
    print(f"{toy['name']} — {toy['pieces']} piezas")
```
