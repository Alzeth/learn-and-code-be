# Lección 9
## Objetivo
Familiarizarse con el manejo de errores. Escribir un programa que pida un número y gestione los errores de entrada.
## try/except:
```python
try:
    number = int(input("Introduce un número: "))
    print(f"Ingresaste: {number}")
except ValueError:
    print("¡Eso no es un número! Inténtalo de nuevo.")
```
## Tipos de errores: ValueError, ZeroDivisionError, IndexError, KeyError, TypeError
## else y finally:
```python
try:
    number = int(input("Introduce un número: "))
except ValueError:
    print("Error: eso no es un número")
else:
    print(f"¡Perfecto! Ingresaste {number}")
finally:
    print("Programa finalizado")
```
## Programa safe_input.py:
```python
while True:
    try:
        number = int(input("Introduce un número entero: "))
        break
    except ValueError:
        print("¡Error! Introduce solo un número, sin letras ni espacios.")
print(f"¡Gracias! Ingresaste el número {number}.")
```
