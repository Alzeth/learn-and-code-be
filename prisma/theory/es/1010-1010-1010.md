## Juego completo guess.py:
```python
import random
def get_guess():
    while True:
        try:
            return int(input("Tu suposición: "))
        except ValueError:
            print("¡Introduce un número entero!")
def play():
    secret = random.randint(1, 100)
    attempts = 0
    print("Pensé un número del 1 al 100. ¡Intenta adivinarlo!")
    while True:
        guess = get_guess()
        attempts += 1
        if guess < secret:
            print("¡Más alto! Inténtalo de nuevo.")
        elif guess > secret:
            print("¡Más bajo! Inténtalo de nuevo.")
        else:
            print(f"¡Correcto! Adivinaste en {attempts} intentos.")
            break
play()
```
## Ideas para mejorar: limitar los intentos, guardar el récord, niveles de dificultad, jugar de nuevo
