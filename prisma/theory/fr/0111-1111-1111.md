# Leçon 1

## Objectif

Apprendre à écrire des programmes simples. Vérifier la configuration de l'environnement de programmation.

## Outils

- Le travail principal se fera dans le terminal
- Nous n'avons besoin que de la ligne de commande, dans laquelle nous envoyons des commandes textuelles
- Un éditeur de texte de base suffit pour saisir le code du programme
- Nous allons d'abord lancer le programme classique `Hello, World!`
- Nous utiliserons la fonction intégrée `print()`

## Premier programme

Créons un nouveau fichier `filename.py` et ajoutons-y notre code.
Le programme le plus simple tient en une seule ligne :

```python
print("Hello, World!")
```

On peut lancer le programme en tapant dans le terminal :

```bash
python filename.py
```

Résultat :

```
Hello, World!
```

## Caractéristiques de ce programme

Ce programme :

- ne prend aucune donnée en entrée
- affiche des données dans le terminal
- ne contient ni boucles ni répétitions

## Exemples supplémentaires

`print()` peut accepter plusieurs paramètres — un espace entre eux apparaîtra automatiquement :

```python
# Ceci est un commentaire — il n'affecte pas le code
print('Hello,', 'World!')
```

Une autre façon — la concaténation (assemblage) de chaînes :

```python
# Notez l'espace à la fin du premier mot
print('Hello, ' + 'World!')
```

> **Remarque :** les fonctions sont des parties de code que nous écrivons nous-mêmes,
> ou des blocs déjà prêts avec des données d'entrée et de sortie.
