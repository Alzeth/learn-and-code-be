## Objectif

Étudier les variables et les types de données. Écrire un programme qui affiche un prénom et un âge.

## Qu'est-ce qu'une variable ?

Une variable est une cellule mémoire nommée dans laquelle nous stockons une valeur. Imaginez une boîte avec une étiquette : l'étiquette est le nom de la variable, et ce qu'il y a à l'intérieur est sa valeur.

```python
name = "Alexandre"
age = 12
```

## Types de données principaux

| Type | Nom | Exemple |
|------|-----|---------|
| `str` | Chaîne (texte) | `"Bonjour"` |
| `int` | Nombre entier | `42` |
| `float` | Nombre décimal | `3.14` |
| `bool` | Valeur logique | `True`, `False` |

On peut connaître le type d'une variable grâce à la fonction `type()` :

```python
name = "Alexandre"
age = 12
print(type(name))   # <class 'str'>
print(type(age))    # <class 'int'>
```

## Premier programme

Créons le fichier `lesson2.py` avec un programme qui affiche un prénom et un âge :

```python
name = "Alexandre"
age = 12

print("Je m'appelle", name)
print("J'ai", age, "ans")
```

Résultat :

```
Je m'appelle Alexandre
J'ai 12 ans
```

## Insertion de variables dans une chaîne (f-string)

La façon la plus pratique d'insérer des variables dans du texte est d'utiliser les **f-strings**. On place la lettre `f` avant les guillemets, et les variables s'écrivent entre accolades `{}` :

```python
name = "Alexandre"
age = 12

print(f"Je m'appelle {name}, j'ai {age} ans.")
```

Résultat :

```
Je m'appelle Alexandre, j'ai 12 ans.
```

## Saisie de données par l'utilisateur

La fonction `input()` permet de recevoir du texte de l'utilisateur depuis le clavier :

```python
name = input("Comment tu t'appelles ? ")
age = input("Quel âge as-tu ? ")

print(f"Bonjour, {name} ! Tu as {age} ans.")
```

> **Attention :** `input()` renvoie toujours une chaîne (`str`). Pour obtenir un nombre, il faut convertir : `age = int(input("Âge : "))`.
