## Objectif

Se familiariser avec les opérations sur les nombres. Créer une calculatrice d'addition et de soustraction.

## Opérations arithmétiques

Python sait effectuer toutes les opérations mathématiques de base :

| Opération | Symbole | Exemple | Résultat |
|-----------|---------|---------|----------|
| Addition | `+` | `5 + 3` | `8` |
| Soustraction | `-` | `10 - 4` | `6` |
| Multiplication | `*` | `3 * 7` | `21` |
| Division | `/` | `9 / 2` | `4.5` |
| Division entière | `//` | `9 // 2` | `4` |
| Reste de la division | `%` | `9 % 2` | `1` |
| Puissance | `**` | `2 ** 8` | `256` |

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

## Conversion de types

Pour effectuer des calculs avec des nombres saisis par l'utilisateur, il faut convertir la chaîne en nombre :

```python
text = "42"
number = int(text)    # chaîne → nombre entier
price = float("3.99") # chaîne → nombre décimal
```

## Calculatrice

Créons le fichier `calculator.py` :

```python
a = int(input("Entrez le premier nombre : "))
b = int(input("Entrez le deuxième nombre : "))

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
```

Exemple de fonctionnement :

```
Entrez le premier nombre : 8
Entrez le deuxième nombre : 3
8 + 3 = 11
8 - 3 = 5
```

## Ordre des opérations

Python respecte les règles mathématiques habituelles : d'abord `**`, puis `*`, `/`, `//`, `%`, et seulement ensuite `+`, `-`. Pour modifier l'ordre, utilisez des parenthèses :

```python
print(2 + 3 * 4)    # 14  (la multiplication en premier)
print((2 + 3) * 4)  # 20  (les parenthèses en premier)
```

> **Conseil :** en cas de doute — mettez des parenthèses. Elles rendent le code plus lisible.
