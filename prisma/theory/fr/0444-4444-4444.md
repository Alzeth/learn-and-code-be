# Leçon 4

## Objectif

Étudier les instructions conditionnelles (if, else). Écrire un programme qui détermine si un nombre est pair.

## Qu'est-ce qu'une instruction conditionnelle ?

Une instruction conditionnelle permet au programme de **prendre des décisions** : exécuter du code différent selon qu'une condition est remplie ou non.

```python
if condition:
    # ce bloc s'exécute si la condition est True
else:
    # ce bloc s'exécute si la condition est False
```

> **Important :** les indentations (4 espaces ou Tab) font partie de la syntaxe Python. Sans elles, le code ne fonctionne pas.

## Opérateurs de comparaison

| Opérateur | Signification | Exemple |
|-----------|---------------|---------|
| `==` | égal à | `5 == 5` → `True` |
| `!=` | différent de | `5 != 3` → `True` |
| `>` | supérieur à | `7 > 3` → `True` |
| `<` | inférieur à | `2 < 9` → `True` |
| `>=` | supérieur ou égal à | `5 >= 5` → `True` |
| `<=` | inférieur ou égal à | `4 <= 6` → `True` |

## Pair ou impair ?

Un nombre est pair si le reste de sa division par 2 est égal à zéro (`number % 2 == 0`).

Créons le fichier `even_odd.py` :

```python
number = int(input("Entrez un nombre : "))

if number % 2 == 0:
    print(f"{number} est un nombre pair")
else:
    print(f"{number} est un nombre impair")
```

Exemple de fonctionnement :

```
Entrez un nombre : 7
7 est un nombre impair
```

## Plusieurs conditions : elif

Quand il y a plus de deux cas, utilisez `elif` (abréviation de "else if") :

```python
score = int(input("Entrez la note : "))

if score >= 90:
    print("Excellent !")
elif score >= 70:
    print("Bien")
elif score >= 50:
    print("Passable")
else:
    print("Il faut plus de pratique")
```

## Opérateurs logiques

Les conditions peuvent être combinées :

| Opérateur | Signification | Exemple |
|-----------|---------------|---------|
| `and` | et | `x > 0 and x < 10` |
| `or` | ou | `x < 0 or x > 100` |
| `not` | non | `not x == 5` |

```python
age = int(input("Quel âge as-tu ? "))

if age >= 6 and age <= 12:
    print("Tu es un élève de l'école primaire")
```

> **Conseil :** lis la condition à voix haute — si elle sonne naturellement, c'est qu'elle est bien écrite.
