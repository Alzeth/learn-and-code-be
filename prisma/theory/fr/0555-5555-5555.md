# Leçon 5

## Objectif

Se familiariser avec les boucles (for, while). Créer un programme qui compte de 1 à 10.

## À quoi servent les boucles ?

Une boucle permet de **répéter** un bloc de code plusieurs fois sans le copier manuellement. Sans boucle, afficher les nombres de 1 à 10 ressemblerait à ceci :

```python
print(1)
print(2)
# ... et encore 8 lignes
```

Avec une boucle — c'est beaucoup plus court.

## La boucle for

La boucle `for` est pratique quand on sait à l'avance combien de fois répéter.

La fonction `range(n)` génère des nombres de `0` à `n-1` :

```python
for i in range(10):
    print(i)   # affichera 0, 1, 2, ..., 9
```

Pour compter de `1` à `10` :

```python
for i in range(1, 11):
    print(i)
```

Résultat :

```
1
2
3
...
10
```

`range()` accepte aussi un pas — le troisième argument :

```python
for i in range(0, 20, 2):
    print(i)   # 0, 2, 4, 6, ..., 18 (nombres pairs seulement)
```

## La boucle while

La boucle `while` se répète **tant qu'une condition est vraie** :

```python
count = 1

while count <= 10:
    print(count)
    count += 1   # identique à count = count + 1
```

Résultat — identique : les nombres de 1 à 10.

## break et continue

- `break` — **arrête** la boucle prématurément
- `continue` — **passe** l'itération courante et passe à la suivante

```python
for i in range(1, 11):
    if i == 5:
        continue   # passer 5
    if i == 8:
        break      # s'arrêter à 8
    print(i)

# Affichera : 1 2 3 4 6 7
```

## Quand utiliser quoi ?

| Situation | Boucle |
|-----------|--------|
| Nombre de répétitions connu | `for` |
| Répéter tant qu'une condition est vraie | `while` |
| Parcourir les éléments d'une liste | `for` |

> **Attention :** si la condition `while` ne devient jamais fausse — la boucle sera infinie. Vérifiez toujours que la variable dans la condition change à l'intérieur de la boucle.
