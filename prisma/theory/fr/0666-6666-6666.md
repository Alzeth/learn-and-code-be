# Leçon 6

## Objectif

Étudier les listes. Écrire un programme qui stocke les prénoms d'amis et les affiche.

## Qu'est-ce qu'une liste ?

Une liste (`list`) est une collection ordonnée de valeurs dans une seule variable. Imaginez une liste comme une armoire numérotée avec des étagères.

```python
friends = ["Alexandre", "Marie", "Thomas", "Sophie"]
```

## Accès aux éléments

Les éléments sont numérotés à partir de **0** (pas de 1) :

```python
friends = ["Alexandre", "Marie", "Thomas", "Sophie"]

print(friends[0])   # Alexandre
print(friends[1])   # Marie
print(friends[-1])  # Sophie (dernier élément)
```

## Opérations principales

```python
friends = ["Alexandre", "Marie"]

# Ajouter un élément à la fin
friends.append("Thomas")

# Connaître le nombre d'éléments
print(len(friends))   # 3

# Vérifier la présence d'un élément
print("Marie" in friends)   # True

# Supprimer un élément par valeur
friends.remove("Marie")

# Supprimer un élément par index
del friends[0]
```

## Parcourir une liste avec une boucle

La façon la plus pratique d'afficher tous les éléments — la boucle `for` :

```python
friends = ["Alexandre", "Marie", "Thomas", "Sophie"]

for friend in friends:
    print(f"Bonjour, {friend} !")
```

Résultat :

```
Bonjour, Alexandre !
Bonjour, Marie !
Bonjour, Thomas !
Bonjour, Sophie !
```

## Programme avec la liste d'amis

Créons le fichier `friends.py` :

```python
friends = []

print("Ajoutez les prénoms de vos amis (ligne vide pour terminer) :")

while True:
    name = input("Prénom : ")
    if name == "":
        break
    friends.append(name)

print(f"\nVos amis ({len(friends)}) :")
for i, friend in enumerate(friends, start=1):
    print(f"{i}. {friend}")
```

Exemple de fonctionnement :

```
Prénom : Alexandre
Prénom : Marie
Prénom : 
Vos amis (2) :
1. Alexandre
2. Marie
```

## Méthodes utiles des listes

| Méthode | Ce qu'elle fait |
|---------|----------------|
| `list.append(x)` | Ajoute `x` à la fin |
| `list.insert(i, x)` | Insère `x` à la position `i` |
| `list.remove(x)` | Supprime le premier `x` |
| `list.sort()` | Trie par ordre alphabétique / croissant |
| `list.reverse()` | Inverse la liste |
| `list.index(x)` | Renvoie l'index de `x` |

> **Conseil :** `enumerate()` donne simultanément le numéro d'ordre et la valeur — très pratique pour les listes numérotées.
