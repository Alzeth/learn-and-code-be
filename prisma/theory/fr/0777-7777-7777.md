# Leçon 7

## Objectif

Se familiariser avec les fonctions. Créer une fonction qui salue l'utilisateur par son prénom.

## Qu'est-ce qu'une fonction ?

Une fonction est un **bloc de code nommé** que l'on peut appeler autant de fois que l'on veut. Les fonctions permettent de ne pas répéter le même code.

Vous connaissez déjà des fonctions intégrées : `print()`, `input()`, `len()`, `int()`. Apprenons maintenant à écrire les nôtres.

## Déclaration d'une fonction

```python
def greet(name):
    print(f"Bonjour, {name} !")
```

- `def` — mot-clé pour déclarer une fonction
- `greet` — nom de la fonction
- `name` — paramètre (données d'entrée)
- le corps de la fonction — avec indentation

## Appel d'une fonction

```python
greet("Alexandre")   # Bonjour, Alexandre !
greet("Marie")       # Bonjour, Marie !
greet("Thomas")      # Bonjour, Thomas !
```

Écrit une fois — utilisable autant de fois que nécessaire.

## Fonction avec plusieurs paramètres

```python
def greet(name, time_of_day):
    print(f"Bon{time_of_day}, {name} !")

greet("Alexandre", "jour")   # Bonjour, Alexandre !
greet("Marie", "soir")       # Bonsoir, Marie !
```

## Valeurs par défaut

On peut donner à un paramètre une valeur utilisée si l'argument n'est pas passé :

```python
def greet(name, time_of_day="jour"):
    print(f"Bon{time_of_day}, {name} !")

greet("Thomas")            # Bonjour, Thomas !
greet("Thomas", "matin")   # Bonmatin, Thomas !
```

## Renvoi d'une valeur

Une fonction peut **renvoyer** un résultat grâce à `return` :

```python
def add(a, b):
    return a + b

result = add(5, 3)
print(result)   # 8
```

Après `return`, la fonction se termine — le code suivant dans la fonction ne s'exécute pas.

## Programme complet

Créons le fichier `greeting.py` :

```python
def greet(name):
    print(f"Bonjour, {name} ! Nous sommes ravis de vous voir.")

def farewell(name):
    print(f"Au revoir, {name} ! À la prochaine fois.")

name = input("Comment tu t'appelles ? ")
greet(name)
farewell(name)
```

Exemple de fonctionnement :

```
Comment tu t'appelles ? Alexandre
Bonjour, Alexandre ! Nous sommes ravis de vous voir.
Au revoir, Alexandre ! À la prochaine fois.
```

> **Conseil :** donnez aux fonctions des noms verbaux qui décrivent leur action : `greet`, `calculate`, `print_result`. Ainsi le code se lit comme du texte ordinaire.
