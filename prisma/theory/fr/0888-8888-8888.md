## Objectif

Étudier les dictionnaires. Écrire un programme qui stocke des informations sur les jouets préférés.

## Qu'est-ce qu'un dictionnaire ?

Un dictionnaire (`dict`) est une collection de paires **clé : valeur**. Contrairement à une liste (où les éléments sont numérotés), dans un dictionnaire chaque valeur a son propre nom unique — la clé.

Imaginez un vrai dictionnaire : mot (clé) → explication (valeur).

```python
toy = {
    "name": "Lego",
    "color": "multicolore",
    "pieces": 500
}
```

## Accès aux valeurs

```python
toy = {"name": "Lego", "color": "multicolore", "pieces": 500}

print(toy["name"])    # Lego
print(toy["pieces"])  # 500
```

La façon la plus sûre — la méthode `.get()` (renvoie `None` au lieu d'une erreur si la clé n'existe pas) :

```python
print(toy.get("price"))        # None
print(toy.get("price", "—"))   # —  (valeur par défaut)
```

## Ajout et modification

```python
toy = {"name": "Lego"}

toy["color"] = "rouge"      # ajouter une nouvelle clé
toy["name"] = "Lego City"   # modifier une valeur existante

print(toy)   # {'name': 'Lego City', 'color': 'rouge'}
```

## Suppression

```python
del toy["color"]      # supprimer par clé
toy.pop("pieces")     # supprimer et récupérer la valeur
```

## Parcourir un dictionnaire

```python
toy = {"name": "Lego", "color": "rouge", "pieces": 500}

# clés seulement
for key in toy:
    print(key)

# valeurs seulement
for value in toy.values():
    print(value)

# clé et valeur ensemble
for key, value in toy.items():
    print(f"{key}: {value}")
```

## Programme avec les jouets

Créons le fichier `toys.py` :

```python
toys = {}

print("Ajoutez des informations sur votre jouet préféré :")
name = input("Nom : ")
color = input("Couleur : ")
pieces = input("Nombre de pièces (ou Entrée) : ")

toys[name] = {
    "color": color,
    "pieces": int(pieces) if pieces else None
}

print("\nVotre jouet :")
for key, value in toys[name].items():
    if value is not None:
        print(f"  {key}: {value}")
```

Exemple de fonctionnement :

```
Nom : Lego
Couleur : rouge
Nombre de pièces : 250

Votre jouet :
  color: rouge
  pieces: 250
```

## Liste de dictionnaires

Les dictionnaires sont souvent stockés dans des listes pour décrire une collection d'objets :

```python
toys = [
    {"name": "Lego", "pieces": 500},
    {"name": "Puzzle", "pieces": 1000},
    {"name": "Rubik's Cube", "pieces": 26},
]

for toy in toys:
    print(f"{toy['name']} — {toy['pieces']} pièces")
```

> **Conseil :** utilisez les dictionnaires quand les données ont des noms (prénom, âge, couleur). Utilisez les listes quand seul l'ordre compte.
