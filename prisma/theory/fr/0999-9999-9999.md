# Leçon 9

## Objectif

Se familiariser avec la gestion des erreurs. Écrire un programme qui demande de saisir un nombre et gère les erreurs de saisie.

## Que sont les erreurs ?

Quand un programme rencontre quelque chose d'inattendu — il s'arrête et affiche une **erreur (exception)**. Par exemple, si on essaie de convertir du texte en nombre :

```python
number = int("bonjour")   # ValueError: invalid literal for int()
```

Pour que le programme ne plante pas, il faut **intercepter** l'erreur.

## La construction try / except

```python
try:
    # code qui peut provoquer une erreur
    number = int(input("Entrez un nombre : "))
    print(f"Vous avez saisi : {number}")
except ValueError:
    print("Ce n'est pas un nombre ! Réessayez.")
```

- Le bloc `try` — s'exécute en premier
- Le bloc `except` — s'exécute seulement si une erreur du type indiqué s'est produite dans `try`

## Types d'erreurs

| Type | Quand elle se produit |
|------|-----------------------|
| `ValueError` | Format de valeur incorrect (`int("abc")`) |
| `ZeroDivisionError` | Division par zéro (`10 / 0`) |
| `IndexError` | Accès hors des limites d'une liste (`list[100]`) |
| `KeyError` | Clé de dictionnaire absente (`dict["xxx"]`) |
| `TypeError` | Types incompatibles (`"5" + 5`) |

On peut intercepter plusieurs types à la fois :

```python
try:
    result = int(input("Nombre : ")) / int(input("Diviseur : "))
    print(result)
except ValueError:
    print("Entrez un nombre entier")
except ZeroDivisionError:
    print("La division par zéro est impossible !")
```

## Les blocs else et finally

- `else` — s'exécute si **aucune erreur** n'a eu lieu
- `finally` — s'exécute **toujours**, quelle que soit l'erreur

```python
try:
    number = int(input("Entrez un nombre : "))
except ValueError:
    print("Erreur : ce n'est pas un nombre")
else:
    print(f"Parfait ! Vous avez saisi {number}")
finally:
    print("Programme terminé")
```

## Programme avec vérification de la saisie

Créons le fichier `safe_input.py` — le programme ne se terminera pas tant que l'utilisateur n'aura pas saisi un nombre correct :

```python
while True:
    try:
        number = int(input("Entrez un nombre entier : "))
        break   # on sort de la boucle si la saisie est correcte
    except ValueError:
        print("Erreur ! Entrez uniquement un nombre, sans lettres ni espaces.")

print(f"Merci ! Vous avez saisi le nombre {number}.")
```

Exemple de fonctionnement :

```
Entrez un nombre entier : bonjour
Erreur ! Entrez uniquement un nombre, sans lettres ni espaces.
Entrez un nombre entier : 3.14
Erreur ! Entrez uniquement un nombre, sans lettres ni espaces.
Entrez un nombre entier : 42
Merci ! Vous avez saisi le nombre 42.
```

> **Règle :** interceptez seulement les erreurs que vous attendez et savez gérer. N'écrivez pas `except Exception` sans raison — cela peut masquer de vrais bugs dans le programme.
