## Le module random

Pour que l'ordinateur choisisse un nombre aléatoire, nous utilisons le module intégré `random` :

```python
import random

secret = random.randint(1, 100)   # entier aléatoire de 1 à 100
print(secret)
```

`import` importe un module prêt à l'emploi. `random.randint(a, b)` renvoie un nombre aléatoire **inclusivement** entre `a` et `b`.

## Construction pas à pas du jeu

### Étape 1 — choisir un nombre

```python
import random

secret = random.randint(1, 100)
```

### Étape 2 — demander une proposition

```python
guess = int(input("Devinez un nombre de 1 à 100 : "))
```

### Étape 3 — comparer et donner un indice

```python
if guess < secret:
    print("Plus grand !")
elif guess > secret:
    print("Plus petit !")
else:
    print("Correct !")
```

### Étape 4 — répéter jusqu'à la bonne réponse

```python
while guess != secret:
    guess = int(input("Réessayez : "))
    if guess < secret:
        print("Plus grand !")
    elif guess > secret:
        print("Plus petit !")

print("Correct !")
```

## Jeu complet

Créons le fichier `guess.py` :

```python
import random

def get_guess():
    while True:
        try:
            return int(input("Votre proposition : "))
        except ValueError:
            print("Entrez un nombre entier !")

def play():
    secret = random.randint(1, 100)
    attempts = 0

    print("J'ai choisi un nombre de 1 à 100. Essayez de le deviner !")

    while True:
        guess = get_guess()
        attempts += 1

        if guess < secret:
            print("Plus grand ! Réessayez.")
        elif guess > secret:
            print("Plus petit ! Réessayez.")
        else:
            print(f"Correct ! Vous avez trouvé en {attempts} essais.")
            break

play()
```

Exemple de fonctionnement :

```
J'ai choisi un nombre de 1 à 100. Essayez de le deviner !
Votre proposition : 50
Plus grand ! Réessayez.
Votre proposition : 75
Plus petit ! Réessayez.
Votre proposition : 63
Correct ! Vous avez trouvé en 3 essais.
```

## Idées pour améliorer le jeu

Le jeu est prêt — mais on peut le rendre encore plus intéressant :

- Limiter le nombre d'essais (par exemple 7) et afficher "Vous avez perdu !" s'ils sont épuisés
- Enregistrer le record (le moins d'essais) et l'afficher après chaque partie
- Permettre au joueur de choisir le niveau de difficulté : facile (1–10), moyen (1–100), difficile (1–1000)
- Demander si le joueur veut rejouer
