# Lezione 1

## Obiettivo

Imparare a scrivere programmi semplici. Verificare la configurazione dell'ambiente di programmazione.

## Strumenti

- Il lavoro principale si svolge nel terminale
- Abbiamo bisogno solo della riga di comando, in cui inviamo comandi testuali
- Per scrivere il codice del programma è sufficiente un editor di testo di base
- Prima eseguiamo il classico programma `Hello, World!`
- Utilizziamo la funzione integrata `print()`

## Il primo programma

Creiamo un nuovo file `filename.py` e aggiungiamo il nostro codice.
Il programma più semplice si inserisce in una sola riga:

```python
print("Hello, World!")
```

Per eseguire il programma, digitare nel terminale:

```bash
python filename.py
```

Risultato:

```
Hello, World!
```

## Caratteristiche di questo programma

Questo programma:

- non accetta dati in ingresso
- stampa dati nel terminale
- non contiene cicli e ripetizioni

## Esempi aggiuntivi

`print()` può accettare più parametri — tra di essi apparirà automaticamente uno spazio:

```python
# Questo è un commento — non influisce sul codice
print('Hello,', 'World!')
```

Un altro modo — la concatenazione (unione) di stringhe:

```python
# Notare lo spazio alla fine della prima parola
print('Hello, ' + 'World!')
```

> **Nota:** le funzioni sono parti di codice che scriviamo noi stessi,
> oppure blocchi già pronti con dati in ingresso e in uscita.
