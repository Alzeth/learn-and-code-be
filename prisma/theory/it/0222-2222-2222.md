## Obiettivo

Studiare le variabili e i tipi di dati. Scrivere un programma che stampa il nome e l'età.

## Che cos'è una variabile?

Una variabile è una cella di memoria con un nome, in cui memorizziamo un valore. Immagina una scatola con un'etichetta: l'etichetta è il nome della variabile, e ciò che è all'interno è il suo valore.

```python
name = "Alessandro"
age = 12
```

## Tipi di dati principali

| Tipo | Nome | Esempio |
|------|------|---------|
| `str` | Stringa (testo) | `"Ciao"` |
| `int` | Numero intero | `42` |
| `float` | Numero decimale | `3.14` |
| `bool` | Valore logico | `True`, `False` |

Per scoprire il tipo di una variabile si usa la funzione `type()`:

```python
name = "Alessandro"
age = 12
print(type(name))   # <class 'str'>
print(type(age))    # <class 'int'>
```

## Il primo programma

Creiamo il file `lesson2.py` con un programma che stampa il nome e l'età:

```python
name = "Alessandro"
age = 12

print("Mi chiamo", name)
print("Ho", age, "anni")
```

Risultato:

```
Mi chiamo Alessandro
Ho 12 anni
```

## Inserimento di variabili nella stringa (f-string)

Un modo più comodo per inserire variabili nel testo è usare le **f-stringhe**. Si mette la lettera `f` prima delle virgolette e le variabili si scrivono tra parentesi graffe `{}`:

```python
name = "Alessandro"
age = 12

print(f"Mi chiamo {name}, ho {age} anni.")
```

Risultato:

```
Mi chiamo Alessandro, ho 12 anni.
```

## Inserimento di dati dall'utente

La funzione `input()` permette di ricevere testo dall'utente tramite la tastiera:

```python
name = input("Come ti chiami? ")
age = input("Quanti anni hai? ")

print(f"Ciao, {name}! Hai {age} anni.")
```

> **Attenzione:** `input()` restituisce sempre una stringa (`str`). Per ottenere un numero occorre convertirla: `age = int(input("Età: "))`.
