## Operazioni aritmetiche

Python sa eseguire tutte le principali operazioni matematiche:

| Operazione | Simbolo | Esempio | Risultato |
|------------|---------|---------|-----------|
| Addizione | `+` | `5 + 3` | `8` |
| Sottrazione | `-` | `10 - 4` | `6` |
| Moltiplicazione | `*` | `3 * 7` | `21` |
| Divisione | `/` | `9 / 2` | `4.5` |
| Divisione intera | `//` | `9 // 2` | `4` |
| Resto della divisione | `%` | `9 % 2` | `1` |
| Potenza | `**` | `2 ** 8` | `256` |

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

## Conversione di tipi

Per eseguire calcoli matematici con numeri inseriti dall'utente, occorre convertire la stringa in numero:

```python
text = "42"
number = int(text)    # stringa → numero intero
price = float("3.99") # stringa → numero decimale
```

## Calcolatrice

Creiamo il file `calculator.py`:

```python
a = int(input("Inserisci il primo numero: "))
b = int(input("Inserisci il secondo numero: "))

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
```

Esempio di esecuzione:

```
Inserisci il primo numero: 8
Inserisci il secondo numero: 3
8 + 3 = 11
8 - 3 = 5
```

## Ordine di esecuzione delle operazioni

Python segue le normali regole matematiche: prima `**`, poi `*`, `/`, `//`, `%`, e infine `+`, `-`. Per cambiare l'ordine si usano le parentesi:

```python
print(2 + 3 * 4)    # 14  (prima la moltiplicazione)
print((2 + 3) * 4)  # 20  (prima le parentesi)
```

> **Consiglio:** se hai dubbi — metti le parentesi. Rendono il codice più comprensibile.
