## Obiettivo

Studiare gli operatori condizionali (if, else). Scrivere un programma che determina se un numero è pari.

## Che cos'è un operatore condizionale?

L'operatore condizionale permette al programma di **prendere decisioni**: eseguire codice diverso a seconda che una certa condizione sia soddisfatta o meno.

```python
if condizione:
    # questo blocco viene eseguito se la condizione è True
else:
    # questo blocco viene eseguito se la condizione è False
```

> **Importante:** i rientri (4 spazi o Tab) sono parte della sintassi di Python. Senza di essi il codice non funziona.

## Operatori di confronto

| Operatore | Significato | Esempio |
|-----------|-------------|---------|
| `==` | uguale | `5 == 5` → `True` |
| `!=` | diverso | `5 != 3` → `True` |
| `>` | maggiore | `7 > 3` → `True` |
| `<` | minore | `2 < 9` → `True` |
| `>=` | maggiore o uguale | `5 >= 5` → `True` |
| `<=` | minore o uguale | `4 <= 6` → `True` |

## Pari o dispari?

Un numero è pari se il resto della divisione per 2 è uguale a zero (`number % 2 == 0`).

Creiamo il file `even_odd.py`:

```python
number = int(input("Inserisci un numero: "))

if number % 2 == 0:
    print(f"{number} è un numero pari")
else:
    print(f"{number} è un numero dispari")
```

Esempio di esecuzione:

```
Inserisci un numero: 7
7 è un numero dispari
```

## Più condizioni: elif

Se i casi sono più di due, si usa `elif` (abbreviazione di "else if"):

```python
score = int(input("Inserisci il voto: "))

if score >= 90:
    print("Eccellente!")
elif score >= 70:
    print("Buono")
elif score >= 50:
    print("Sufficiente")
else:
    print("Bisogna esercitarsi di più")
```

## Operatori logici

Le condizioni possono essere combinate:

| Operatore | Significato | Esempio |
|-----------|-------------|---------|
| `and` | e | `x > 0 and x < 10` |
| `or` | o | `x < 0 or x > 100` |
| `not` | non | `not x == 5` |

```python
age = int(input("Quanti anni hai? "))

if age >= 6 and age <= 12:
    print("Sei uno studente delle scuole elementari")
```

> **Consiglio:** leggi la condizione ad alta voce — se suona in modo naturale, allora è scritta correttamente.
