# Lezione 5

## Obiettivo

Familiarizzare con i cicli (for, while). Creare un programma che conta da 1 a 10.

## A cosa servono i cicli?

Un ciclo permette di **ripetere** un blocco di codice più volte, senza copiarlo manualmente. Senza un ciclo, stampare i numeri da 1 a 10 apparirebbe così:

```python
print(1)
print(2)
# ... e altre 8 righe
```

Con un ciclo — molto più corto.

## Ciclo for

Il ciclo `for` è comodo da usare quando si sa in anticipo quante volte ripetere.

La funzione `range(n)` genera numeri da `0` a `n-1`:

```python
for i in range(10):
    print(i)   # stamperà 0, 1, 2, ..., 9
```

Per contare da `1` a `10`:

```python
for i in range(1, 11):
    print(i)
```

Risultato:

```
1
2
3
...
10
```

`range()` accetta anche un passo — il terzo argomento:

```python
for i in range(0, 20, 2):
    print(i)   # 0, 2, 4, 6, ..., 18 (solo i pari)
```

## Ciclo while

Il ciclo `while` si ripete **finché la condizione è vera**:

```python
count = 1

while count <= 10:
    print(count)
    count += 1   # equivale a count = count + 1
```

Risultato — uguale: i numeri da 1 a 10.

## break e continue

- `break` — **interrompe** il ciclo anticipatamente
- `continue` — **salta** l'iterazione corrente e passa alla successiva

```python
for i in range(1, 11):
    if i == 5:
        continue   # salta il 5
    if i == 8:
        break      # fermati all'8
    print(i)

# Stamperà: 1 2 3 4 6 7
```

## Quando usare cosa?

| Situazione | Ciclo |
|------------|-------|
| Numero di ripetizioni noto | `for` |
| Ripetere finché la condizione è vera | `while` |
| Scorrere gli elementi di una lista | `for` |

> **Attenzione:** se la condizione di `while` non diventa mai falsa — il ciclo sarà infinito. Verifica sempre che la variabile nella condizione cambi all'interno del ciclo.
