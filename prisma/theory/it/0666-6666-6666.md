## Obiettivo

Studiare le liste. Scrivere un programma che memorizza i nomi degli amici e li stampa.

## Che cos'è una lista?

Una lista (`list`) è una collezione ordinata di valori in una singola variabile. Immagina una lista come un armadio numerato con ripiani.

```python
friends = ["Alessandro", "Maria", "Marco", "Sofia"]
```

## Accesso agli elementi

Gli elementi sono numerati a partire da **0** (non da 1):

```python
friends = ["Alessandro", "Maria", "Marco", "Sofia"]

print(friends[0])   # Alessandro
print(friends[1])   # Maria
print(friends[-1])  # Sofia (ultimo elemento)
```

## Operazioni principali

```python
friends = ["Alessandro", "Maria"]

# Aggiungere un elemento alla fine
friends.append("Marco")

# Conoscere il numero di elementi
print(len(friends))   # 3

# Verificare la presenza di un elemento
print("Maria" in friends)   # True

# Rimuovere un elemento per valore
friends.remove("Maria")

# Rimuovere un elemento per indice
del friends[0]
```

## Scorrere la lista con un ciclo

Il modo più comodo per stampare tutti gli elementi è il ciclo `for`:

```python
friends = ["Alessandro", "Maria", "Marco", "Sofia"]

for friend in friends:
    print(f"Ciao, {friend}!")
```

Risultato:

```
Ciao, Alessandro!
Ciao, Maria!
Ciao, Marco!
Ciao, Sofia!
```

## Programma con la lista degli amici

Creiamo il file `friends.py`:

```python
friends = []

print("Aggiungi i nomi degli amici (riga vuota per terminare):")

while True:
    name = input("Nome: ")
    if name == "":
        break
    friends.append(name)

print(f"\nI tuoi amici ({len(friends)}):")
for i, friend in enumerate(friends, start=1):
    print(f"{i}. {friend}")
```

Esempio di esecuzione:

```
Nome: Alessandro
Nome: Maria
Nome: 
I tuoi amici (2):
1. Alessandro
2. Maria
```

## Metodi utili della lista

| Metodo | Cosa fa |
|--------|---------|
| `list.append(x)` | Aggiunge `x` alla fine |
| `list.insert(i, x)` | Inserisce `x` nella posizione `i` |
| `list.remove(x)` | Rimuove il primo `x` |
| `list.sort()` | Ordina alfabeticamente / in modo crescente |
| `list.reverse()` | Inverte la lista |
| `list.index(x)` | Restituisce l'indice di `x` |

> **Consiglio:** `enumerate()` fornisce contemporaneamente il numero ordinale e il valore — molto comodo per le liste numerate.
