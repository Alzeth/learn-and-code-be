## Obiettivo

Familiarizzare con le funzioni. Creare una funzione che saluta l'utente per nome.

## Che cos'è una funzione?

Una funzione è un **blocco di codice con un nome**, che può essere chiamato un numero qualsiasi di volte. Le funzioni aiutano a non ripetere lo stesso codice.

Hai già familiarità con le funzioni integrate: `print()`, `input()`, `len()`, `int()`. Ora impariamo a scriverne di proprie.

## Dichiarazione di una funzione

```python
def greet(name):
    print(f"Ciao, {name}!")
```

- `def` — parola chiave per la dichiarazione di una funzione
- `greet` — nome della funzione
- `name` — parametro (dati in ingresso)
- il corpo della funzione — con il rientro

## Chiamata di una funzione

```python
greet("Alessandro")   # Ciao, Alessandro!
greet("Maria")        # Ciao, Maria!
greet("Marco")        # Ciao, Marco!
```

Scritta una volta — può essere usata tutte le volte che si vuole.

## Funzione con più parametri

```python
def greet(name, time_of_day):
    print(f"Buon {time_of_day}, {name}!")

greet("Alessandro", "giorno")   # Buon giorno, Alessandro!
greet("Maria", "sera")          # Buon sera, Maria!
```

## Valori predefiniti

A un parametro si può assegnare un valore che viene usato se l'argomento non viene passato:

```python
def greet(name, time_of_day="giorno"):
    print(f"Buon {time_of_day}, {name}!")

greet("Marco")              # Buon giorno, Marco!
greet("Marco", "mattino")   # Buon mattino, Marco!
```

## Restituzione di un valore

Una funzione può **restituire** un risultato tramite `return`:

```python
def add(a, b):
    return a + b

result = add(5, 3)
print(result)   # 8
```

Dopo `return` la funzione termina — il codice successivo al suo interno non viene eseguito.

## Programma completo

Creiamo il file `greeting.py`:

```python
def greet(name):
    print(f"Ciao, {name}! Siamo felici di vederti.")

def farewell(name):
    print(f"Arrivederci, {name}! Ci vediamo alla prossima.")

name = input("Come ti chiami? ")
greet(name)
farewell(name)
```

Esempio di esecuzione:

```
Come ti chiami? Alessandro
Ciao, Alessandro! Siamo felici di vederti.
Arrivederci, Alessandro! Ci vediamo alla prossima.
```

> **Consiglio:** dai alle funzioni nomi verbali che descrivono la loro azione: `greet`, `calculate`, `print_result`. In questo modo il codice si legge come un testo normale.
