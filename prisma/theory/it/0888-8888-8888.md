## Obiettivo

Studiare i dizionari. Scrivere un programma che memorizza informazioni sui giocattoli preferiti.

## Che cos'è un dizionario?

Un dizionario (`dict`) è una collezione di coppie **chiave: valore**. A differenza di una lista (dove gli elementi sono numerati), in un dizionario ogni valore ha il proprio nome-chiave univoco.

Immagina un dizionario reale: la parola (chiave) → la spiegazione (valore).

```python
toy = {
    "name": "Lego",
    "color": "multicolore",
    "pieces": 500
}
```

## Accesso ai valori

```python
toy = {"name": "Lego", "color": "multicolore", "pieces": 500}

print(toy["name"])    # Lego
print(toy["pieces"])  # 500
```

Un modo più sicuro è il metodo `.get()` (restituisce `None` invece di un errore se la chiave non esiste):

```python
print(toy.get("price"))        # None
print(toy.get("price", "—"))   # —  (valore predefinito)
```

## Aggiunta e modifica

```python
toy = {"name": "Lego"}

toy["color"] = "rosso"      # aggiungere una nuova chiave
toy["name"] = "Lego City"   # modificare un valore esistente

print(toy)   # {'name': 'Lego City', 'color': 'rosso'}
```

## Eliminazione

```python
del toy["color"]      # eliminare per chiave
toy.pop("pieces")     # eliminare e ottenere il valore
```

## Scorrere il dizionario

```python
toy = {"name": "Lego", "color": "rosso", "pieces": 500}

# solo le chiavi
for key in toy:
    print(key)

# solo i valori
for value in toy.values():
    print(value)

# chiave e valore insieme
for key, value in toy.items():
    print(f"{key}: {value}")
```

## Programma con i giocattoli

Creiamo il file `toys.py`:

```python
toys = {}

print("Aggiungi informazioni sul tuo giocattolo preferito:")
name = input("Nome: ")
color = input("Colore: ")
pieces = input("Numero di pezzi (o Invio): ")

toys[name] = {
    "color": color,
    "pieces": int(pieces) if pieces else None
}

print("\nIl tuo giocattolo:")
for key, value in toys[name].items():
    if value is not None:
        print(f"  {key}: {value}")
```

Esempio di esecuzione:

```
Nome: Lego
Colore: rosso
Numero di pezzi: 250

Il tuo giocattolo:
  color: rosso
  pieces: 250
```

## Lista di dizionari

I dizionari vengono spesso memorizzati in liste per descrivere una collezione di oggetti:

```python
toys = [
    {"name": "Lego", "pieces": 500},
    {"name": "Puzzle", "pieces": 1000},
    {"name": "Cubo di Rubik", "pieces": 26},
]

for toy in toys:
    print(f"{toy['name']} — {toy['pieces']} pezzi")
```

> **Consiglio:** usa i dizionari quando i dati hanno nomi (nome, età, colore). Usa le liste quando conta solo l'ordine.
