## Obiettivo

Familiarizzare con la gestione degli errori. Scrivere un programma che chiede di inserire un numero e gestisce gli errori di input.

## Che cosa sono gli errori?

Quando un programma incontra qualcosa di inaspettato — si interrompe e mostra un **errore (eccezione)**. Ad esempio, se si prova a convertire del testo in numero:

```python
number = int("ciao")   # ValueError: invalid literal for int()
```

Per evitare che il programma si blocchi, occorre **intercettare** l'errore.

## Costrutto try / except

```python
try:
    # codice che potrebbe generare un errore
    number = int(input("Inserisci un numero: "))
    print(f"Hai inserito: {number}")
except ValueError:
    print("Questo non è un numero! Riprova.")
```

- Il blocco `try` — viene eseguito per primo
- Il blocco `except` — viene eseguito solo se in `try` si è verificato un errore del tipo indicato

## Tipi di errori

| Tipo | Quando si verifica |
|------|--------------------|
| `ValueError` | Formato del valore errato (`int("abc")`) |
| `ZeroDivisionError` | Divisione per zero (`10 / 0`) |
| `IndexError` | Accesso oltre i limiti della lista (`list[100]`) |
| `KeyError` | Chiave del dizionario assente (`dict["xxx"]`) |
| `TypeError` | Tipi incompatibili (`"5" + 5`) |

Si possono intercettare più tipi contemporaneamente:

```python
try:
    result = int(input("Numero: ")) / int(input("Divisore: "))
    print(result)
except ValueError:
    print("Inserisci un numero intero")
except ZeroDivisionError:
    print("Non si può dividere per zero!")
```

## Blocco else e finally

- `else` — viene eseguito se **non ci sono stati** errori
- `finally` — viene eseguito **sempre**, indipendentemente dagli errori

```python
try:
    number = int(input("Inserisci un numero: "))
except ValueError:
    print("Errore: questo non è un numero")
else:
    print(f"Ottimo! Hai inserito {number}")
finally:
    print("Programma terminato")
```

## Programma con verifica dell'input

Creiamo il file `safe_input.py` — il programma non termina finché l'utente non inserisce un numero corretto:

```python
while True:
    try:
        number = int(input("Inserisci un numero intero: "))
        break   # usciamo dal ciclo se l'input è corretto
    except ValueError:
        print("Errore! Inserisci proprio un numero, senza lettere e spazi.")

print(f"Grazie! Hai inserito il numero {number}.")
```

Esempio di esecuzione:

```
Inserisci un numero intero: ciao
Errore! Inserisci proprio un numero, senza lettere e spazi.
Inserisci un numero intero: 3.14
Errore! Inserisci proprio un numero, senza lettere e spazi.
Inserisci un numero intero: 42
Grazie! Hai inserito il numero 42.
```

> **Regola:** intercetta solo gli errori che ti aspetti e sai come gestire. Non scrivere `except Exception` senza motivo — potrebbe nascondere dei veri bug nel programma.
