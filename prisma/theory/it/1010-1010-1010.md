## Modulo random

Per far indovinare al computer un numero casuale, usiamo il modulo integrato `random`:

```python
import random

secret = random.randint(1, 100)   # intero casuale da 1 a 100
print(secret)
```

`import` collega un modulo già pronto. `random.randint(a, b)` restituisce un numero casuale **inclusi** `a` e `b`.

## Costruzione passo dopo passo del gioco

### Passo 1 — il computer sceglie un numero

```python
import random

secret = random.randint(1, 100)
```

### Passo 2 — chiedere all'utente di inserire un'ipotesi

```python
guess = int(input("Indovina il numero da 1 a 100: "))
```

### Passo 3 — confrontare e dare un suggerimento

```python
if guess < secret:
    print("Più alto!")
elif guess > secret:
    print("Più basso!")
else:
    print("Corretto!")
```

### Passo 4 — ripetere fino alla risposta giusta

```python
while guess != secret:
    guess = int(input("Riprova: "))
    if guess < secret:
        print("Più alto!")
    elif guess > secret:
        print("Più basso!")

print("Corretto!")
```

## Gioco completo

Creiamo il file `guess.py`:

```python
import random

def get_guess():
    while True:
        try:
            return int(input("La tua ipotesi: "))
        except ValueError:
            print("Inserisci un numero intero!")

def play():
    secret = random.randint(1, 100)
    attempts = 0

    print("Ho pensato un numero da 1 a 100. Prova a indovinarlo!")

    while True:
        guess = get_guess()
        attempts += 1

        if guess < secret:
            print("Più alto! Riprova.")
        elif guess > secret:
            print("Più basso! Riprova.")
        else:
            print(f"Corretto! Hai indovinato in {attempts} tentativi.")
            break

play()
```

Esempio di esecuzione:

```
Ho pensato un numero da 1 a 100. Prova a indovinarlo!
La tua ipotesi: 50
Più alto! Riprova.
La tua ipotesi: 75
Più basso! Riprova.
La tua ipotesi: 63
Corretto! Hai indovinato in 3 tentativi.
```

## Idee per migliorare

Il gioco è pronto — ma lo si può rendere più interessante:

- Limitare il numero di tentativi (ad esempio 7) e mostrare "Hai perso!" se si esauriscono
- Memorizzare il record (il minor numero di tentativi) e mostrarlo dopo ogni partita
- Permettere al giocatore di scegliere il livello di difficoltà: facile (1–10), medio (1–100), difficile (1–1000)
- Chiedere al giocatore se vuole giocare ancora
