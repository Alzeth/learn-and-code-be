# Lekcja 1

## Cel

Nauczyć się pisać proste programy. Sprawdzić konfigurację środowiska programistycznego.

## Narzędzia

- Główna praca odbywa się w terminalu
- Potrzebujemy jedynie wiersza poleceń, do którego wysyłamy polecenia tekstowe
- Do pisania kodu wystarczy podstawowy edytor tekstu
- Na początku uruchomimy klasyczny program `Hello, World!`
- Użyjemy wbudowanej funkcji `print()`

## Pierwszy program

Utwórzmy nowy plik `filename.py` i dodajmy do niego nasz kod.
Najprostszy program mieści się w jednej linii:

```python
print("Hello, World!")
```

Uruchomić program można wpisując w terminalu:

```bash
python filename.py
```

Wynik:

```
Hello, World!
```

## Cechy tego programu

Ten program:

- nie przyjmuje danych wejściowych
- wyświetla dane w terminalu
- nie zawiera pętli ani powtórzeń

## Dodatkowe przykłady

`print()` może przyjmować kilka parametrów — spacja między nimi pojawi się automatycznie:

```python
# To jest komentarz — nie wpływa na kod
print('Hello,', 'World!')
```

Inny sposób — konkatenacja (łączenie) łańcuchów:

```python
# Zwróć uwagę na spację na końcu pierwszego słowa
print('Hello, ' + 'World!')
```

> **Uwaga:** funkcje to fragmenty kodu, które piszemy sami,
> lub gotowe bloki z danymi wejściowymi i wyjściowymi.
