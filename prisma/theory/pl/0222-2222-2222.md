## Czym jest zmienna?

Zmienna to nazwana komórka pamięci, w której przechowujemy wartość. Wyobraź sobie pudełko z etykietą: etykieta to nazwa zmiennej, a to, co w środku — jej wartość.

```python
name = "Aleksander"
age = 12
```

## Podstawowe typy danych

| Typ | Nazwa | Przykład |
|-----|-------|---------|
| `str` | Łańcuch (tekst) | `"Cześć"` |
| `int` | Liczba całkowita | `42` |
| `float` | Liczba zmiennoprzecinkowa | `3.14` |
| `bool` | Wartość logiczna | `True`, `False` |

Typ zmiennej można sprawdzić za pomocą funkcji `type()`:

```python
name = "Aleksander"
age = 12
print(type(name))   # <class 'str'>
print(type(age))    # <class 'int'>
```

## Pierwszy program

Utwórzmy plik `lesson2.py` z programem, który wyświetla imię i wiek:

```python
name = "Aleksander"
age = 12

print("Mam na imię", name)
print("Mam", age, "lat")
```

Wynik:

```
Mam na imię Aleksander
Mam 12 lat
```

## Wstawianie zmiennych do łańcucha (f-string)

Wygodniejszy sposób wstawiania zmiennych do tekstu — użycie **f-stringów**. Przed cudzysłowem stawiamy literę `f`, a zmienne piszemy w nawiasach klamrowych `{}`:

```python
name = "Aleksander"
age = 12

print(f"Mam na imię {name} i mam {age} lat.")
```

Wynik:

```
Mam na imię Aleksander i mam 12 lat.
```

## Wprowadzanie danych od użytkownika

Funkcja `input()` pozwala pobrać tekst od użytkownika z klawiatury:

```python
name = input("Jak masz na imię? ")
age = input("Ile masz lat? ")

print(f"Cześć, {name}! Masz {age} lat.")
```

> **Uwaga:** `input()` zawsze zwraca łańcuch (`str`). Aby uzyskać liczbę, trzeba wykonać konwersję: `age = int(input("Wiek: "))`.
