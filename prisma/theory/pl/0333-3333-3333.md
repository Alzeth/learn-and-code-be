## Operacje arytmetyczne

Python potrafi wykonywać wszystkie podstawowe działania matematyczne:

| Operacja | Symbol | Przykład | Wynik |
|----------|--------|---------|-------|
| Dodawanie | `+` | `5 + 3` | `8` |
| Odejmowanie | `-` | `10 - 4` | `6` |
| Mnożenie | `*` | `3 * 7` | `21` |
| Dzielenie | `/` | `9 / 2` | `4.5` |
| Dzielenie całkowite | `//` | `9 // 2` | `4` |
| Reszta z dzielenia | `%` | `9 % 2` | `1` |
| Potęgowanie | `**` | `2 ** 8` | `256` |

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

## Konwersja typów

Aby wykonywać matematykę na liczbach wprowadzonych przez użytkownika, trzeba przekonwertować łańcuch na liczbę:

```python
text = "42"
number = int(text)    # łańcuch → liczba całkowita
price = float("3.99") # łańcuch → liczba zmiennoprzecinkowa
```

## Kalkulator

Utwórzmy plik `calculator.py`:

```python
a = int(input("Podaj pierwszą liczbę: "))
b = int(input("Podaj drugą liczbę: "))

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
```

Przykład działania:

```
Podaj pierwszą liczbę: 8
Podaj drugą liczbę: 3
8 + 3 = 11
8 - 3 = 5
```

## Kolejność wykonywania operacji

Python stosuje zwykłe reguły matematyczne: najpierw `**`, następnie `*`, `/`, `//`, `%`, a dopiero potem `+`, `-`. Aby zmienić kolejność, używaj nawiasów:

```python
print(2 + 3 * 4)    # 14  (najpierw mnożenie)
print((2 + 3) * 4)  # 20  (najpierw nawiasy)
```

> **Wskazówka:** jeśli masz wątpliwości — postaw nawiasy. Sprawiają, że kod jest bardziej czytelny.
