## Cel

Poznać instrukcje warunkowe (if, else). Napisać program, który sprawdza, czy liczba jest parzysta.

## Czym jest instrukcja warunkowa?

Instrukcja warunkowa pozwala programowi **podejmować decyzje**: wykonywać różny kod w zależności od tego, czy spełniony jest określony warunek.

```python
if warunek:
    # ten blok wykonuje się, gdy warunek jest True
else:
    # ten blok wykonuje się, gdy warunek jest False
```

> **Ważne:** wcięcia (4 spacje lub Tab) są częścią składni Pythona. Bez nich kod nie działa.

## Operatory porównania

| Operator | Znaczenie | Przykład |
|----------|----------|---------|
| `==` | równy | `5 == 5` → `True` |
| `!=` | różny | `5 != 3` → `True` |
| `>` | większy niż | `7 > 3` → `True` |
| `<` | mniejszy niż | `2 < 9` → `True` |
| `>=` | większy lub równy | `5 >= 5` → `True` |
| `<=` | mniejszy lub równy | `4 <= 6` → `True` |

## Parzyste czy nieparzyste?

Liczba jest parzysta, jeśli reszta z dzielenia przez 2 wynosi zero (`number % 2 == 0`).

Utwórzmy plik `even_odd.py`:

```python
number = int(input("Podaj liczbę: "))

if number % 2 == 0:
    print(f"{number} — liczba parzysta")
else:
    print(f"{number} — liczba nieparzysta")
```

Przykład działania:

```
Podaj liczbę: 7
7 — liczba nieparzysta
```

## Wiele warunków: elif

Gdy wariantów jest więcej niż dwa, używaj `elif` (skrót od "else if"):

```python
score = int(input("Podaj ocenę: "))

if score >= 90:
    print("Celujący!")
elif score >= 70:
    print("Dobry")
elif score >= 50:
    print("Dostateczny")
else:
    print("Trzeba więcej ćwiczyć")
```

## Operatory logiczne

Warunki można łączyć:

| Operator | Znaczenie | Przykład |
|----------|----------|---------|
| `and` | i | `x > 0 and x < 10` |
| `or` | lub | `x < 0 or x > 100` |
| `not` | nie | `not x == 5` |

```python
age = int(input("Ile masz lat? "))

if age >= 6 and age <= 12:
    print("Jesteś uczniem szkoły podstawowej")
```

> **Wskazówka:** czytaj warunek na głos — jeśli brzmi naturalnie, to jest napisany poprawnie.
