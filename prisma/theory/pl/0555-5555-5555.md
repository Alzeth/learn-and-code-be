## Cel

Zapoznać się z pętlami (for, while). Stworzyć program, który liczy od 1 do 10.

## Po co są pętle?

Pętla pozwala **powtarzać** blok kodu wielokrotnie, bez ręcznego kopiowania. Bez pętli wypisanie liczb od 1 do 10 wyglądałoby tak:

```python
print(1)
print(2)
# ... i jeszcze 8 linii
```

Z pętlą — o wiele krócej.

## Pętla for

Pętla `for` jest wygodna, gdy z góry wiadomo, ile razy powtarzać.

Funkcja `range(n)` generuje liczby od `0` do `n-1`:

```python
for i in range(10):
    print(i)   # wypisze 0, 1, 2, ..., 9
```

Aby liczyć od `1` do `10`:

```python
for i in range(1, 11):
    print(i)
```

Wynik:

```
1
2
3
...
10
```

`range()` przyjmuje też krok — trzeci argument:

```python
for i in range(0, 20, 2):
    print(i)   # 0, 2, 4, 6, ..., 18 (tylko parzyste)
```

## Pętla while

Pętla `while` powtarza się, **dopóki spełniony jest warunek**:

```python
count = 1

while count <= 10:
    print(count)
    count += 1   # to samo co count = count + 1
```

Wynik — taki sam: liczby od 1 do 10.

## break i continue

- `break` — **zatrzymuje** pętlę przedwcześnie
- `continue` — **pomija** bieżącą iterację i przechodzi do następnej

```python
for i in range(1, 11):
    if i == 5:
        continue   # pomiń 5
    if i == 8:
        break      # zatrzymaj się na 8
    print(i)

# Wypisze: 1 2 3 4 6 7
```

## Kiedy czego używać?

| Sytuacja | Pętla |
|----------|-------|
| Znana liczba powtórzeń | `for` |
| Powtarzaj, dopóki spełniony jest warunek | `while` |
| Przeglądanie elementów listy | `for` |

> **Ostrożnie:** jeśli warunek `while` nigdy nie stanie się fałszywy — pętla będzie nieskończona. Zawsze sprawdzaj, że zmienna w warunku zmienia się wewnątrz pętli.
