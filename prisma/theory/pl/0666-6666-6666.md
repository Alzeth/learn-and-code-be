## Cel

Poznać listy. Napisać program, który przechowuje imiona znajomych i wyświetla je.

## Czym jest lista?

Lista (`list`) to uporządkowana kolekcja wartości w jednej zmiennej. Wyobraź sobie listę jako ponumerowaną szafę z półkami.

```python
friends = ["Aleksander", "Maria", "Jan", "Zofia"]
```

## Odwoływanie się do elementów

Elementy są numerowane od **0** (nie od 1):

```python
friends = ["Aleksander", "Maria", "Jan", "Zofia"]

print(friends[0])   # Aleksander
print(friends[1])   # Maria
print(friends[-1])  # Zofia (ostatni element)
```

## Podstawowe operacje

```python
friends = ["Aleksander", "Maria"]

# Dodaj element na końcu
friends.append("Jan")

# Sprawdź liczbę elementów
print(len(friends))   # 3

# Sprawdź obecność elementu
print("Maria" in friends)   # True

# Usuń element według wartości
friends.remove("Maria")

# Usuń element według indeksu
del friends[0]
```

## Przeglądanie listy pętlą

Najwygodniejszy sposób wypisania wszystkich elementów — pętla `for`:

```python
friends = ["Aleksander", "Maria", "Jan", "Zofia"]

for friend in friends:
    print(f"Cześć, {friend}!")
```

Wynik:

```
Cześć, Aleksander!
Cześć, Maria!
Cześć, Jan!
Cześć, Zofia!
```

## Program z listą znajomych

Utwórzmy plik `friends.py`:

```python
friends = []

print("Dodaj imiona znajomych (pusty wiersz — zakończ):")

while True:
    name = input("Imię: ")
    if name == "":
        break
    friends.append(name)

print(f"\nTwoi znajomi ({len(friends)}):")
for i, friend in enumerate(friends, start=1):
    print(f"{i}. {friend}")
```

Przykład działania:

```
Imię: Aleksander
Imię: Maria
Imię: 
Twoi znajomi (2):
1. Aleksander
2. Maria
```

## Przydatne metody listy

| Metoda | Co robi |
|--------|---------|
| `list.append(x)` | Dodaje `x` na końcu |
| `list.insert(i, x)` | Wstawia `x` na pozycję `i` |
| `list.remove(x)` | Usuwa pierwszy `x` |
| `list.sort()` | Sortuje alfabetycznie / rosnąco |
| `list.reverse()` | Odwraca listę |
| `list.index(x)` | Zwraca indeks `x` |

> **Wskazówka:** `enumerate()` jednocześnie daje numer porządkowy i wartość — bardzo wygodne do list numerowanych.
