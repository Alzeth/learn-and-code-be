## Cel

Zapoznać się z funkcjami. Stworzyć funkcję, która wita użytkownika po imieniu.

## Czym jest funkcja?

Funkcja to **nazwany blok kodu**, który można wywołać dowolną liczbę razy. Funkcje pomagają uniknąć powtarzania tego samego kodu.

Znasz już wbudowane funkcje: `print()`, `input()`, `len()`, `int()`. Teraz nauczymy się pisać własne.

## Deklaracja funkcji

```python
def greet(name):
    print(f"Cześć, {name}!")
```

- `def` — słowo kluczowe do deklaracji funkcji
- `greet` — nazwa funkcji
- `name` — parametr (dane wejściowe)
- ciało funkcji — z wcięciem

## Wywołanie funkcji

```python
greet("Aleksander")   # Cześć, Aleksander!
greet("Maria")        # Cześć, Maria!
greet("Jan")          # Cześć, Jan!
```

Raz napisana — można używać tyle razy, ile potrzeba.

## Funkcja z kilkoma parametrami

```python
def greet(name, time_of_day):
    print(f"Dzień dobry {time_of_day}, {name}!")

greet("Aleksander", "rano")    # Dzień dobry rano, Aleksander!
greet("Maria", "wieczorem")    # Dzień dobry wieczorem, Maria!
```

## Wartości domyślne

Parametrowi można nadać wartość, która jest używana, gdy argument nie zostanie przekazany:

```python
def greet(name, time_of_day="w ciągu dnia"):
    print(f"Dzień dobry {time_of_day}, {name}!")

greet("Jan")                    # Dzień dobry w ciągu dnia, Jan!
greet("Jan", "rano")            # Dzień dobry rano, Jan!
```

## Zwracanie wartości

Funkcja może **zwracać** wynik za pomocą `return`:

```python
def add(a, b):
    return a + b

result = add(5, 3)
print(result)   # 8
```

Po `return` funkcja kończy działanie — następny kod w niej nie jest wykonywany.

## Pełny program

Utwórzmy plik `greeting.py`:

```python
def greet(name):
    print(f"Cześć, {name}! Miło cię widzieć.")

def farewell(name):
    print(f"Do widzenia, {name}! Do zobaczenia następnym razem.")

name = input("Jak masz na imię? ")
greet(name)
farewell(name)
```

Przykład działania:

```
Jak masz na imię? Aleksander
Cześć, Aleksander! Miło cię widzieć.
Do widzenia, Aleksander! Do zobaczenia następnym razem.
```

> **Wskazówka:** nadawaj funkcjom nazwy czasownikowe opisujące ich działanie: `greet`, `calculate`, `print_result`. Dzięki temu kod czyta się jak zwykły tekst.
