Poznać słowniki. Napisać program, który przechowuje informacje o ulubionych zabawkach.

## Czym jest słownik?

Słownik (`dict`) to kolekcja par **klucz: wartość**. W odróżnieniu od listy (gdzie elementy są ponumerowane), w słowniku każda wartość ma swoją unikalną nazwę-klucz.

Wyobraź sobie prawdziwy słownik: słowo (klucz) → wyjaśnienie (wartość).

```python
toy = {
    "name": "Klocki LEGO",
    "color": "różnokolorowe",
    "pieces": 500
}
```

## Dostęp do wartości

```python
toy = {"name": "Klocki LEGO", "color": "różnokolorowe", "pieces": 500}

print(toy["name"])    # Klocki LEGO
print(toy["pieces"])  # 500
```

Bezpieczniejszy sposób — metoda `.get()` (zwraca `None` zamiast błędu, gdy klucz nie istnieje):

```python
print(toy.get("price"))        # None
print(toy.get("price", "—"))   # —  (wartość domyślna)
```

## Dodawanie i zmiana

```python
toy = {"name": "Klocki LEGO"}

toy["color"] = "czerwone"         # dodaj nowy klucz
toy["name"] = "Klocki LEGO City"  # zmień istniejącą wartość

print(toy)   # {'name': 'Klocki LEGO City', 'color': 'czerwone'}
```

## Usuwanie

```python
del toy["color"]      # usuń według klucza
toy.pop("pieces")     # usuń i pobierz wartość
```

## Przeglądanie słownika

```python
toy = {"name": "Klocki LEGO", "color": "czerwone", "pieces": 500}

# tylko klucze
for key in toy:
    print(key)

# tylko wartości
for value in toy.values():
    print(value)

# klucz i wartość razem
for key, value in toy.items():
    print(f"{key}: {value}")
```

## Program z zabawkami

Utwórzmy plik `toys.py`:

```python
toys = {}

print("Dodaj informacje o ulubionej zabawce:")
name = input("Nazwa: ")
color = input("Kolor: ")
pieces = input("Liczba elementów (lub Enter): ")

toys[name] = {
    "color": color,
    "pieces": int(pieces) if pieces else None
}

print("\nTwoja zabawka:")
for key, value in toys[name].items():
    if value is not None:
        print(f"  {key}: {value}")
```

Przykład działania:

```
Nazwa: Klocki LEGO
Kolor: czerwone
Liczba elementów: 250

Twoja zabawka:
  color: czerwone
  pieces: 250
```

## Lista słowników

Słowniki często przechowuje się w listach, aby opisać kolekcję obiektów:

```python
toys = [
    {"name": "Klocki LEGO", "pieces": 500},
    {"name": "Puzzle", "pieces": 1000},
    {"name": "Kostka Rubika", "pieces": 26},
]

for toy in toys:
    print(f"{toy['name']} — {toy['pieces']} elementów")
```

> **Wskazówka:** używaj słowników, gdy dane mają nazwy (imię, wiek, kolor). Używaj list, gdy ważna jest tylko kolejność.
