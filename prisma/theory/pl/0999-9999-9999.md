## Cel

Zapoznać się z obsługą błędów. Napisać program, który prosi o wprowadzenie liczby i obsługuje błędy wprowadzania.

## Czym są błędy?

Gdy program natrafi na coś nieoczekiwanego — zatrzymuje się i wyświetla **błąd (wyjątek)**. Na przykład, gdy spróbujemy przekonwertować tekst na liczbę:

```python
number = int("cześć")   # ValueError: invalid literal for int()
```

Aby program się nie zawieszał, trzeba **przechwycić** błąd.

## Konstrukcja try / except

```python
try:
    # kod, który może wywołać błąd
    number = int(input("Podaj liczbę: "))
    print(f"Wpisałeś: {number}")
except ValueError:
    print("To nie jest liczba! Spróbuj ponownie.")
```

- Blok `try` — wykonuje się najpierw
- Blok `except` — wykonuje się tylko wtedy, gdy w `try` wystąpił błąd wskazanego typu

## Typy błędów

| Typ | Kiedy występuje |
|-----|----------------|
| `ValueError` | Nieprawidłowy format wartości (`int("abc")`) |
| `ZeroDivisionError` | Dzielenie przez zero (`10 / 0`) |
| `IndexError` | Odwołanie poza granice listy (`list[100]`) |
| `KeyError` | Brakujący klucz słownika (`dict["xxx"]`) |
| `TypeError` | Niezgodne typy (`"5" + 5`) |

Można przechwytywać kilka typów jednocześnie:

```python
try:
    result = int(input("Liczba: ")) / int(input("Dzielnik: "))
    print(result)
except ValueError:
    print("Podaj liczbę całkowitą")
except ZeroDivisionError:
    print("Nie można dzielić przez zero!")
```

## Blok else i finally

- `else` — wykonuje się, gdy **nie było** błędów
- `finally` — wykonuje się **zawsze**, niezależnie od błędów

```python
try:
    number = int(input("Podaj liczbę: "))
except ValueError:
    print("Błąd: to nie jest liczba")
else:
    print(f"Świetnie! Wpisałeś {number}")
finally:
    print("Program zakończony")
```

## Program ze sprawdzaniem wprowadzenia

Utwórzmy plik `safe_input.py` — program nie zakończy się, dopóki użytkownik nie wprowadzi poprawnej liczby:

```python
while True:
    try:
        number = int(input("Podaj liczbę całkowitą: "))
        break   # wychodzimy z pętli, gdy wprowadzenie jest poprawne
    except ValueError:
        print("Błąd! Podaj samą liczbę, bez liter i spacji.")

print(f"Dziękuję! Wpisałeś liczbę {number}.")
```

Przykład działania:

```
Podaj liczbę całkowitą: cześć
Błąd! Podaj samą liczbę, bez liter i spacji.
Podaj liczbę całkowitą: 3.14
Błąd! Podaj samą liczbę, bez liter i spacji.
Podaj liczbę całkowitą: 42
Dziękuję! Wpisałeś liczbę 42.
```

> **Zasada:** przechwytuj tylko te błędy, których się spodziewasz i które potrafisz obsłużyć. Nie pisz `except Exception` bez potrzeby — może to ukryć prawdziwe błędy w programie.
