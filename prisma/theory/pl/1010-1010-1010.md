## Moduł random

Aby komputer wylosował liczbę, użyjemy wbudowanego modułu `random`:

```python
import random

secret = random.randint(1, 100)   # losowa liczba całkowita od 1 do 100
print(secret)
```

`import` podłącza gotowy moduł. `random.randint(a, b)` zwraca losową liczbę **włącznie** z `a` i `b`.

## Budowanie gry krok po kroku

### Krok 1 — wylosuj liczbę

```python
import random

secret = random.randint(1, 100)
```

### Krok 2 — poproś o zgadnięcie

```python
guess = int(input("Zgadnij liczbę od 1 do 100: "))
```

### Krok 3 — porównaj i podpowiedz

```python
if guess < secret:
    print("Za mało!")
elif guess > secret:
    print("Za dużo!")
else:
    print("Trafiłeś!")
```

### Krok 4 — powtarzaj do poprawnej odpowiedzi

```python
while guess != secret:
    guess = int(input("Spróbuj jeszcze raz: "))
    if guess < secret:
        print("Za mało!")
    elif guess > secret:
        print("Za dużo!")

print("Trafiłeś!")
```

## Pełna gra

Utwórzmy plik `guess.py`:

```python
import random

def get_guess():
    while True:
        try:
            return int(input("Twoja odpowiedź: "))
        except ValueError:
            print("Podaj liczbę całkowitą!")

def play():
    secret = random.randint(1, 100)
    attempts = 0

    print("Pomyślałem o liczbie od 1 do 100. Spróbuj zgadnąć!")

    while True:
        guess = get_guess()
        attempts += 1

        if guess < secret:
            print("Za mało! Spróbuj jeszcze.")
        elif guess > secret:
            print("Za dużo! Spróbuj jeszcze.")
        else:
            print(f"Trafiłeś! Zgadłeś za {attempts} prób.")
            break

play()
```

Przykład działania:

```
Pomyślałem o liczbie od 1 do 100. Spróbuj zgadnąć!
Twoja odpowiedź: 50
Za mało! Spróbuj jeszcze.
Twoja odpowiedź: 75
Za dużo! Spróbuj jeszcze.
Twoja odpowiedź: 63
Trafiłeś! Zgadłeś za 3 prób.
```

## Pomysły na ulepszenia

Gra jest gotowa — ale można ją uczynić ciekawszą:

- Ogranicz liczbę prób (np. 7) i wyświetl "Przegrałeś!", gdy się wyczerpią
- Przechowuj rekord (najmniej prób) i wyświetl go po każdej grze
- Daj graczowi wybór poziomu trudności: łatwy (1–10), średni (1–100), trudny (1–1000)
- Zapytaj, czy gracz chce zagrać jeszcze raz
